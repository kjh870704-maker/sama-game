# 장수 초상 이미지

여기에 넣은 그림은 게임의 초상(인물열전·대화창·전장 장수 정보)으로 쓰입니다.

1. 그림 파일을 이 폴더에 넣습니다. 예: `조조.png`, `사마의.webp`
2. `manifest.json`에 `"장수 이름": "파일 이름"`을 적습니다.
   ```json
   {"조조": "조조.png", "사마의": "사마의.webp"}
   ```

- 얼굴이 위쪽 1/3쯤에 오는 흉상(어깨까지)이 가장 잘 맞습니다.
- 투명 바탕 PNG는 대화창에서 그대로 겹쳐 보입니다.
- 게임 안에서도 넣을 수 있습니다: 인물열전 → 장수 선택 → 「초상 이미지 넣기」. 여러 장을 고르면 파일 이름을 장수 이름으로 봅니다.
- 같은 장수에게 둘 다 있으면 게임 안에서 넣은 그림이 먼저입니다.
