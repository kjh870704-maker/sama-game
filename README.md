# 사마의전 (Sima Yi Chronicle)

> **2026-10-01 개발판:** 8개 고유 전장과 반복 수련 6종·보물 인연 11종, 보물 60종, 성장형 책략과 특성 해금을 구현했습니다. [32전장 설계](./docs/prd/캠페인-32전장-v1.md)와 [최신 구현 범위](./docs/tech/지속개발-현황.md)를 확인하세요.

『삼국지 조조전』의 턴제 전술 SRPG 모델을 기반으로, 사마의의 생애를 3부 32스테이지로 그리는 캠페인.

> **설계 명제:** 플레이어가 느끼는 *조작의 자유도 자체*가 서사다.
> 상편은 통제할 수 없고 → 중편은 적이 판을 짜고 → 하편은 내가 판을 짠다.

## 게임 실행

**Windows:** `게임실행.cmd`를 더블 클릭하면 브라우저에서 게임이 열립니다. Node.js 22 이상이 필요합니다.

```bash
npm ci
npm run dev
# 표시된 로컬 주소로 접속 (기본 http://127.0.0.1:5173)
```

첫 화면에서 **사마가 수비전**으로 시작합니다. 완료하면 **낙양 탈출전**, **육혼산 도주전**, **흉몽**, **장강 퇴각전**, **동관 전투**, **한중 정벌전 上·下**가 차례로 열립니다. 군의에서 출진 특성을 고르고, 연의 지도에서 저장한 전투를 이어갈 수 있습니다. 미제작 전장은 제작 예정으로 표시합니다.

- 왼쪽 부대 목록이나 지도에서 장수를 선택 → 이동 → 공격 / 책략 / 대기.
- 본대 다음에는 **편입 아군을 직접 조작**합니다. 적군과 황금색 우군은 자동 행동합니다.
- 한중: 수비대장을 격파한 뒤 **사마의 또는 조진**이 중앙 성채에서 `성채 점령`을 선택합니다.
- 낙양: **두 형제 모두** 남문에 도착하고 통행료 **1,000전**을 남겨야 합니다. 순찰에 발각되면 대화 선택지가 나옵니다.
- `1` 이동 / `2` 공격 / `3` 풍룡 / `W` 대기 / `Z` 무르기 / `?` 도움말.
- 지도는 휠·버튼으로 확대, 드래그로 이동합니다. 방향키와 Enter도 지원합니다.
- 소리는 출진 클릭 후 시작됩니다. 설정에서 배경음·효과음을 개별 조절합니다.
- 전투와 인장은 현재 브라우저에 저장됩니다. 사이트 데이터를 삭제하면 저장도 사라집니다.

```bash
npm run build           # 코어 + 웹 배포 빌드
npm run preview         # 배포 빌드 로컬 확인
```

웹 결과물은 `packages/web/dist/`입니다. 정적 호스팅 가능하며 서버 비밀키나 외부 API가 필요하지 않습니다.

지속 개발의 다음 작업과 최신 검증은 [개발 현황](./docs/tech/지속개발-현황.md)에 기록합니다.

## 이번 개발판

누적 경험치 성장, 2D 출전 이야기, 60종 보물과 장비, 반복 수련·보물 인연, 단계별 책략·특성 해금, 시나리오별 지도, 성문 HP·감시탑 공격을 반영했습니다. 일반 첫 승리로 Lv.1부터 서서히 성장합니다. 현재 8/32전장을 제작했으며 나머지는 제작 예정입니다. 상세 범위와 한계는 개발 현황을 참고하세요.

## 시작하기

```bash
npm install
npm run typecheck        # 타입 검사
npm test                 # 단위 테스트
npm run validate:stages  # 스테이지 데이터 무결성 검증
npm run sim              # 밸런스 시뮬레이션
```

`npm run sim` 출력 예:

```
스테이지 2개 × 200회 시뮬레이션

✅ S1-02 [normal ] 클리어 100.0% | 평균   3.0턴 | 인장2 100.0% | 인장3 100.0%
⚠️  S1-02 [extreme] 클리어 100.0% | 평균   3.0턴 | ...  ← 목표(35.0%) 대비 과도하게 쉬움
✅ S1-08 [normal ] 클리어  11.0% | 평균   4.0턴 | 인장2  11.0% | 인장3  11.0%
⚠️  S1-08 [extreme] 클리어 100.0% | 평균   4.0턴 | ...  ← 목표(30.0%) 대비 과도하게 쉬움
```

⚠️는 콘텐츠 설계 과제를 가리킨다 — 상세는 [개발 로드맵](./docs/tech/개발-로드맵.md)의 "시뮬레이터가 이미 보고한 설계 과제".

## 핵심 설계 규칙

1. **`packages/core`는 아무것도 import 하지 않는다.** 헤드리스 시뮬레이션이 성립하려면 렌더러·플랫폼 비의존이어야 한다.
2. **스테이지를 추가할 때 코어 코드는 한 줄도 바뀌지 않는다.** 기믹은 트리거/액션 조합으로 표현한다. 코어에 스테이지 ID가 등장하면 설계 위반.
3. **모든 확률은 시드된 RNG 하나에서만 나온다.** 무르기·리플레이·밸런스 QA가 전부 여기서 파생된다.
4. **적 배치는 일반 난이도 기준 1벌만 작성한다.** 극한은 `enemyLevelShift`로 파생시킨다.
5. **피해 감소는 곱연산으로 합성한다.** 덧셈은 무적 유닛을 만든다.

### 지원 병종 편성

수련·보물 인연의 출진 정비에서 지원 두 부대를 선택할 수 있습니다. 주술사(약화), 무녀(정화·방호), 도사(원소), 의술사(회복), 무도가(험지·근접), 궁기병(기동 사격), 산적(숲·산지)을 추가했습니다. 전용 책략은 레벨에 따라 열립니다. 신규 7병종의 전용 도트 그래픽 28프레임을 적용했습니다. 첫 화면의 병종 도감에서 대기·이동·공격·책략/특수 동작을 확인할 수 있습니다.
