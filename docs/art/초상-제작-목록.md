# 장수 초상 제작 목록 (Portrait Production Sheet)

`packages/web/public/portraits/manifest.json`의 유화 초상 제작·등록 지시서입니다. 고정된 “남은 인원” 수는 실제 자산과 쉽게 어긋나므로 적지 않고, 아래 완료표와 manifest를 기준으로 관리합니다.
화가나 이미지 생성 모델이 이미 그려 둔 초상(예: `jia-kui.png`, `cao-ren.png`)과 같은 화풍으로 그릴 수 있도록,
인물마다 게임 속 정보(인물열전 `officer-bios.ts`, 연의 능력·별호 `romance.ts`, 초한 영웅 `chuhan.ts`)를 바탕으로
진영·나이·역할·옷차림을 정해 두었습니다.

This sheet tracks characters that need or have received a painted portrait. Each entry gives the file name, faction,
a one-line Korean description and an English prompt that describes **visual content only**. Always combine it with
the shared STYLE and NEGATIVE blocks below.

## 1. 화풍 규격 (Style spec)

기준 그림: `packages/web/public/portraits/jia-kui.png`

- 사실적인 유화. 머리부터 어깨까지 오는 흉상이고, 얼굴은 화면 위쪽 1/3~1/2 사이에 둡니다.
- 붓자국이 보이는 회화적 질감에 캔버스 결이 드러나야 합니다. 사진처럼 매끈하게 그리지 않습니다.
- 따뜻한 키아로스쿠로(한쪽에서 들어오는 호박색 빛과 깊은 그림자)를 씁니다.
- 배경은 짙은 갈색에 연기가 낀 듯한 단색이고, 소품이나 풍경은 넣지 않습니다.
- 복식은 후한 말·삼국 시대(초한 인물은 진말·한초)에 맞춥니다. 후대 왕조의 관모(복두 등), 판금 갑옷, 판타지 장식은 쓰지 않습니다.
- 글자, 서명, 테두리, 워터마크를 넣지 않습니다. 정사각형 1:1 비율이며, 기존 파일은 1254×1254 PNG입니다.
- 진영 색은 아래 표를 따르되 채도를 낮춘 유화 색으로 칠합니다. 옷의 주색이나 안감, 갑옷 끈에 넣고, 화면 전체를 그 색으로 물들이지는 않습니다.

| 진영 | 색 단서 (colour cue) |
|---|---|
| 위 (사마씨 포함) | deep blue / indigo and black |
| 촉 (서량 출신 포함) | deep green, jade-green, olive |
| 오 | crimson, dark red, red-brown |
| 원소 | muted gold, ochre-yellow, brass |
| 남만·이민족 | tribal: rattan, hide, feathers, bronze, earth tones; 오환은 felt and fur |
| 공손 (요동) | slate grey, dark plum, northern fur |
| 여포 집단 | black with deep plum-crimson and bronze |
| 장로 (한중) | undyed hemp, dull ochre-brown |
| 형주 (유표) | ash-grey and dull teal with bronze |
| 초 (초한) | black lacquer with crimson-red |
| 한 (초한) | earthen ochre-brown with dark indigo |

### STYLE (모든 프롬프트 앞에 붙임)

```text
Realistic oil painting, head-and-shoulders bust portrait, square 1:1 composition, face in the upper third of the frame,
painterly visible brushwork with canvas texture, warm chiaroscuro lighting from one side, deep shadows,
plain dark brown smoky background, historically accurate late Eastern Han / Three Kingdoms Chinese dress,
muted earthy palette, dignified museum-portrait mood.
```

초한 인물(항우~관영)은 두 번째 줄의 시대 표현을 `historically accurate late Qin / early Western Han Chinese dress`로 바꿉니다.

### NEGATIVE (모든 프롬프트 뒤에 붙임)

```text
No text, no letters, no calligraphy, no signature, no watermark, no frame, no border, no logo,
no anime or cartoon style, no 3D render look, no plate armour, no fantasy ornaments, no Tang/Song/Ming headgear,
no extra limbs, no weapons crossing the face, no modern objects.
```

화풍만 지시하고, 특정 게임이나 작품의 디자인 또는 실존 화가 이름은 프롬프트에 넣지 않습니다.

## 2. 파일 이름 규칙 (File naming)

- 표준 중국어 병음을 소문자로 쓰고 성과 이름 사이에 하이픈을 넣은 뒤 `.png`를 붙입니다. 성조 기호는 뺍니다. 예: 양준 → `yang-jun.png`
- 이름 두 글자는 붙여 씁니다(기존 `zhang-chunhua`와 같음). 복성도 붙여 씁니다: `sima-`, `zhuge-`, `xiahou-`, `gongsun-`, `zhongli-`.
- `ü`는 `u`로 씁니다(여포 `lu-bu`, 여몽 `lu-meng`). 이렇게 써도 육손 `lu-xun`, 노숙 `lu-su`와 겹치지 않습니다.
- 이민족의 한 덩어리 이름은 하이픈 없이 씁니다: 올돌골 `wutugu`, 답돈 `tadun`, 타사대왕 `duosi`.
- 같은 인물의 다른 시기는 뒤에 붙임말을 답니다: 소년 사마의 → `sima-yi-young.png`
- **양수**는 기존 비유화 이미지 `yang-xiu.webp`를 대신하므로 `yang-xiu.png`로 만듭니다. manifest 값을 바꾸고 옛 `.webp`는 지웁니다.

## 3. 등록 방법 (How to register)

1. 완성한 PNG를 `packages/web/public/portraits/`에 넣습니다.
2. `packages/web/public/portraits/manifest.json`에 `"이름": "파일"` 한 줄을 더합니다. 키는 게임 속 한국어 이름과 똑같아야 합니다(띄어쓰기 포함).
   ```json
   "양준": "yang-jun.png",
   "소년 사마의": "sima-yi-young.png",
   "양수": "yang-xiu.png"
   ```
3. 게임에서 인물열전을 열어 초상이 뜨는지 확인합니다. 게임 안에서 직접 넣은 그림이 manifest보다 먼저 쓰입니다.
