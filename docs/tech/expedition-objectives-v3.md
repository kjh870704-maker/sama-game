## 조작과 판정
- 호위 대상은 편입 아군 차례에 직접 이동. 대상 퇴각 시 실패.
- 구출 대상은 사마의 또는 조진이 인접하면 아군으로 전환. 이후 서쪽 안전지대까지 이동해야 승리한다. 구출 전에는 적 소속의 수동 부대로 표현하며 공격하면 안 된다. 금빛 테두리·이름과 작전 안내로 구별한다.
- 점령은 사마의 또는 조진이 금빛 지점에서 거점 확보 명령 사용. 전멸 불필요.
- 방어는 5/6/7개의 완전한 턴을 버텨야 승리. 초기 적과 3·5턴 증원 중 한 부대라도 거점에 진입하면 패배. 거점을 아군이 막으면 돌격대가 공격한다. 증원 지점이 모두 점유되면 배치할 수 없다.
- 모든 외전에서 사마의와 조진 생존 필수. 전멸 외 목표는 적을 전멸시켜도 목표를 별도로 수행해야 한다.
- 목록·이야기·정비·전장 상단에 목표 안내. 지도 목표 영역 색상/이름, 보호 대상 테두리·이름, 실패 사유 제공.

## 검증과 후속 범위
- 17개 외전 초기 배치/통행/저장 재생, 기존 v2 호환, 목표별 승패, 구출 편입, 점령 명령, 방어 증원 중복 방지와 거점 수비 공격을 자동 검증.
- 브라우저에서 호위·구출·방어 전장 렌더링과 외전 목록/출진 연결 확인.
- 경험치·수련 횟수·권장 레벨과 전 병종 조합의 실제 플레이 난이도 조율은 사용자 지정 다음 단계. 이번 변경은 목표와 전투 규칙의 다양화이며 전체 밸런스 검증 완료를 뜻하지 않는다.
