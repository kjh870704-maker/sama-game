# 사마의전 플레이어블 제작 노트

## 구현 범위

기준 브랜치: `claude/nice-hypatia-ahpgee`. 기존 TypeScript 코어와 원본 두 스테이지 JSON을 사용한다. 코어·스테이지 원본의 규칙을 교체하지 않고 `packages/web`을 연결했다. 현 결과물은 32전장 완결판이 아닌 2전장 플레이어블 프로토타입이다.

- 낙양 탈출전: 순찰 시야, 형제 이동, 발각 대화, 뇌물/거짓말/교전 분기, 목표 변경, 승리/패배.
- 한중 정벌전: 본대 2기, 직접 조작하는 편입 아군 8기, 자동 우군 7기, 적 수비대, 점령 경쟁, 증원.
- 이동/물리 공격/책략/대기/점령, 전투 기록, 확률을 보존하는 무르기.
- 두 난이도는 시연을 위해 바로 선택 가능. 정식판의 부 완주 후 극한 해금과 다르다.
- 강제 종료는 60턴 초과. 난이도별 권장 레벨 로스터를 사용하며 장비/육성 UI는 아직 없다.
- 풍룡: MP 18, 사거리 4, 중심 및 인접 4칸. 화계: MP 12, 사거리 3, 단일 대상 + 화상. 편입 책사에게도 풍룡을 지급한다.

## 시각 방향

도트의 격자 전술을 유지하면서 벡터 기반 등각 디오라마로 재해석했다. 먹빛 UI, 청록 아군, 푸른 편입 아군, 황금색 자동 우군, 주홍 적군을 구분한다. 황동색은 목표·명령·인장에만 집중한다. 사마의는 창작 SVG 초상, 기타 장수는 병종/성씨 표식으로 표시한다. 모든 장수의 개별 일러스트를 완성한 상태는 아니다.

지형은 평지·길·숲·산지·성벽·성문·성채를 절차적으로 그린다. 병종별 유닛은 직접 그린 캔버스 텍스처를 PixiJS로 표시한다. 이동 보간, 피해 팝업, 책략 타격 범위, 적 시야, 줌/패닝을 지원한다. 별도 외부 이미지나 원작 자산은 사용하지 않는다.

## 사운드

Web Audio로 생성한 창작 오음계 악절을 사용한다. 현을 뜯는 삼각파 음색, 부드러운 사인파 선율과 저음, 한중 전투의 북소리를 합성한다. 선택·이동·공격·책략·턴 교대·승패 효과음이 있다. 실제 전통악기를 녹음한 음원은 아니다.

브라우저 자동재생 정책에 맞춰 출진/이어하기 클릭 이후 오디오를 시작한다. 배경음·효과음 음량을 별도로 조절하고 전체 음소거를 제공한다. 탭을 숨기면 AudioContext를 정지한다. 렌더링과 음향 랜덤은 전투 RNG에 영향을 주지 않는다.

## 저장과 무르기

클라이언트 Session은 시드·스테이지·난이도·명령과 AI tick 기록을 저장한다. 엔진을 새로 조립하고 기록을 재생하므로 순찰 경로, RNG, 반격 횟수, 페이즈가 함께 복원된다. 무르기는 마지막 사용자 명령 이후 AI 행동까지 되돌린다. 코어의 기존 스냅샷 구현에 렌더러 의존성을 추가하지 않았다.

자동 저장은 브라우저 localStorage를 사용한다. 클라우드 동기화는 없다. 비공개 모드/용량 초과 등 저장이 불가능하면 화면에 상태를 표시한다. 저장 형식에 버전을 두어 손상되거나 호환되지 않는 데이터는 이어하기에서 오류로 안내한다. 인장은 난이도를 합산한 데모 진척으로 기록한다.

## 검증

- TypeScript 코어/웹 타입 검사 및 프로덕션 빌드.
- 전투 코어 76개 + 플레이 세션 9개, 총 85개 테스트.
- 원본 맵 2개/스테이지 2개 데이터 검증.
- 낙양 완주/인장/완주 기록 재생, 한중 점령 승리 경로 확인.
- 반격/RNG가 같은 공격 재생, 대화 중 명령 차단, 편입 아군 페이즈, AI 진행 후 무르기.
- 실제 Chrome에서 전장 선택 → 출진 → 지도 클릭 이동 → 뇌물 선택 → 풍룡 → 무르기 → 턴 진행 → 새로고침/이어하기 확인.
- 1440px PC 및 390px 모바일 뷰포트에서 렌더링과 가로 넘침 검사. 실물 저사양 휴대폰 성능 인증은 아직 하지 않았다.
