## 3. 파일 규격 (기존 파일과 같게)

모두 RGBA 투명 바탕 webp. 글자·바닥·그림자·테두리 없음. 인물은 **오른쪽을 본다**(적으로 설 때는 코드가 좌우를 뒤집는다).

### 전용 대결 그림 — `packages/web/public/officers/<id>-duel-v1.webp`
- 1024×256, 가로 4칸(칸 256×256), 1줄.
- 칸 순서(코드가 이렇게 씀 — `style.css`의 `--officer-x`):
  1. 대기(정면 3/4, 무기 든 자세)
  2. 한 걸음·지휘(설전은 공세 자세를 모두 이 칸으로 씀 → 부채·손짓 같은 말하는 자세가 어울린다)
  3. 공격·필살(일기토 공격)
  4. 방어·피격(움츠림)
- 네 칸 모두 발끝을 같은 바닥선에, 같은 크기로. 무기 끝·말 꼬리까지 칸 안에(위·옆 여백 10% 이상).
- 기준 그림: `officers/sima_shi-duel-v1.webp`(말 탐), `officers/cao_pi-duel-v1.webp`, `officer-battle-sima-v2.webp`의 사마의 줄(걸음). **SD가 아닌 6~7등신 정밀 화풍.** 전투 시트의 SD 화풍을 키운 것처럼 보이면 안 된다.

### 전투 시트 — `packages/web/public/officers/<id>-battle-<병종>-v1.webp`
- 걸어서 싸우는 병종: 1120×224(칸 280×224). 말 탄 병종·군주(lord)·중기병: 1400×280(칸 350×280). 가로 4칸, 1줄.
- 칸 순서: 대기 / 한 걸음 / 공격 / 방어. 전장에서는 작게 보이므로 기존 전투 시트(`officers/lu_xun-battle-strategist-v1.webp`, `officers/zhao_yun-battle-heavyCav-v1.webp`)와 같은 화풍이면 된다.
- 병종 그림과 같은 무기·실루엣을 유지(책사는 부채, 노병은 연노 등).

### (P3) 흉상·이야기 전신
- 흉상 `<id>-bust-v1.webp`: 3072×1024, 가로 3칸(1024×1024): 평상·말함·감정.
- 이야기 전신 `<id>-story-v1.webp`: 1280×480, 8칸×3줄(160×160). 기존 `sima_shi-story-v1.webp`과 같은 배치.

## 4. 코드 등록 (그림을 넣은 뒤)

1. `packages/web/src/officer-models.ts`
   - `officerManifest`: 새 장수는 `E('<id>','<이름>',c('<id>','<병종>'[,1,350,280]))` 추가. 대결 그림이 생긴 장수는 네 번째 인자에 `{duel:'officers/<id>-duel-v1.webp'}`.
   - `duelRows`에 `<id>:{sheet:'officers/<id>-duel-v1.webp',row:0,rows:1}` 추가.
   - 말 탄 대결 그림이면 `MOUNTED_DUEL`에 id 추가(조운·여몽·손권·공손연·맹염·비연·조휴·조상·장패 등 병종이 기병·군주인 장수).
2. `packages/web/public/officers/manifest.json`에도 같은 내용(두 색인은 같아야 한다).
3. (P3만) 흉상·전신은 `packages/web/src/officer-art.ts`의 `officerLooks`에 `{id,name,title,slot}` 추가.

## 5. 확인 방법

- `npm run typecheck && npx vitest run`(특히 `officer-models.test.ts`, `officer-art.test.ts`, `battle-art.test.ts`).
- 브라우저: `npm run build` 후 `dist`를 띄우고 `?dev`로 연다.
  - 일기토·설전: 콘솔에서 `__sama.start(장번호)` → 상대 옆에 세우고 `__sama.act({kind:'item',unit:'sima_yi',item:'debate',target:'<id>'})`. 장번호: S1-09=8, S1-10=9, S1-11=10, S2-02=12, S2-03=13, S2-05=15, S2-06=16, S2-07=17, S2-08=18, S2-10=20, S2-12=22, S3-01=25, S3-02=26, S3-03=27, S3-04=28, S3-07=31.
  - 가상 전장: `__sama.run(15,'tale',7,undefined,'<가상 전장 id>')`.
  - 병종 탭 → 장수에서 새 장수 카드가 같은 크기로, 잘림 없이 나오는지.
- 합격 기준: 대결 화면에서 두 인물의 키 차이가 1.2배 이내, 같은 화풍, 머리·무기·말 꼬리 잘림 없음, 네 칸이 서로 다른 자세.
- 화면 크기 1366×768, 1920×1080, 휴대폰 가로 844×390 세 가지로 본다.
