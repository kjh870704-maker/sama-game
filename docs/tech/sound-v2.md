# 사운드 v2 — 삼국지 계열 게임 비교와 전면 개선

## 1. 무엇이 단조로웠나 (v1)
- 효과음 7종이 오실레이터 몇 개로 즉석 합성되어 매번 똑같이 들림.
- 책략은 원소와 상관없이 같은 종소리, 공격은 병종과 상관없이 같은 톱니파.
- 함성·비명·말 울음 같은 "사람과 동물의 소리"가 전혀 없음.
- 좌우 위치, 공간감(잔향), 큰 순간의 강조(음악 줄이기)가 없음.

## 2. 비교한 게임과 참고한 점
원본 음원은 쓰지 않았고, 구성과 역할만 참고했다.

| 게임 | 사운드 구성에서 참고한 점 | 우리 반영 |
|---|---|---|
| 삼국지 조조전·영걸전(코에이 SRPG) | 짧고 또렷한 효과음이 행동 하나에 하나씩 대응. 책략마다 다른 소리(불·물·바위·번개). 부대가 무너질 때 비명, 턴 전환 북·징, 승리 팡파르 | 행동·책략·턴·승패별 전용 음원, 퇴각 비명, 아군/적 턴 북 구분 |
| 삼국지 시리즈(전략) | 전장 시작 뿔나팔·북, 병사 함성, 성문 공략 때 큰 충격음 | 전투 시작(뿔나팔→전고→함성), 성문 돌파(징·붕괴·함성) |
| 진삼국무쌍 | 공격마다 휘두름 + 타격 + 기합을 겹쳐 무게감, 치명타 때 강조 | 휘두름→타격→기합 층 구성, 치명타 시 묵직한 충격과 음악 줄이기 |
| Total War: Three Kingdoms | 다양성·반응성·정통성. 중국 전통 악기 녹음, 오행(목·화·토·금·수)에 맞춘 소리, 원어민 함성 | 변형 여러 개·높낮이 흔들기, 원소별 책략음, 쟁(현)·전고·징·편종 |

참고: [Total War: Three Kingdoms 사운드 설계(게임월드옵저버)](https://gameworldobserver.com/?p=2001), [Behind the audio of Total War: Three Kingdoms(Game Developer)](https://gamedeveloper.com/audio/behind-the-audio-of-i-total-war-three-kingdoms-i-)

## 3. 만드는 방식 (녹음 없이)
`packages/web/src/sound-bank.ts` — 오프라인 DSP로 효과음을 샘플 버퍼로 합성한다.
- **현**: 카플러스-스트롱 물리 모델(쟁 음표, 활시위, 노 시위).
- **금속·나무·종·징**: 모달 합성(감쇠하는 공명 주파수 묶음). 칼 부딪힘, 방패, 편종, 징.
- **북**: 막 공명(떨어지는 기본음 + 비정수배 모드 + 북채 타격).
- **목소리**: 성대 톱니파 + 모음 공명 3개(포먼트). 함성 "와아", 기합 "하앗", 비명 "으아악", 말 울음.
- **자연**: 걸러 낸 잡음 — 불길(울림+탁탁 튐), 돌풍(휘파람 공명), 물보라(거품음), 천둥(번쩍+우르릉).
- 음원마다 서로 다른 시드로 변형 2~3개를 만들고, 재생 때 높낮이 ±4%와 음량을 흔든다. 같은 변형은 연속으로 나오지 않는다.

`packages/web/src/audio.ts` — 재생 엔진.
- 합성 잔향(초기 반사 + 감쇠 꼬리)으로 전장의 공간감.
- 화면 위치에 따라 좌우로 들림(공격자는 시작 위치, 타격은 대상 위치).
- 치명타·충차·포차·성문 돌파·승패 때 배경음을 잠깐 낮춤.
- 동시 발음 18개 제한(중요한 소리 우선).
- 음악의 쟁 소리를 현 물리 모델 음표로, 북·목탁·징·종을 같은 음원으로 교체.

`packages/web/src/sound-events.ts` — 전투 사건 → 음원 묶음.

## 4. 사건별 소리
| 사건 | 소리 |
|---|---|
| 보병·검 공격 | 휘두름 + (칼 부딪힘 또는 갑옷 타격) + 기합(55%) |
| 창병 | 찌르기 바람 + 꿰뚫는 둔탁음 |
| 기병·중기병 | 말발굽 + 묵직한 충돌 + 칼날 울림, 30% 말 울음 |
| 궁병·궁기병 / 노병 | 시위 튕김 + 화살 바람 → 나무 꽂힘 / 기계 걸쇠 + 시위 |
| 포차 / 충차 | 나무 팔 + 발사 → 바위 착탄 / 바퀴 굴림 → 성문 강타 |
| 수군 | 노 젓기 + 함성 → 접현 + 물보라 |
| 빗나감 / 방어 / 치명타 | 휙 피함 / 방패 나무·쇠 / 이중 충격 + 신음 + 음악 줄이기 |
| 화계·풍계·수계·낙뢰·속박·교란 | 불길·돌풍·물보라·천둥·바위와 쇠사슬·일그러진 종 |
| 회복 / 강화 / 수리 | 오음계 종 + 맑은 울림 / 징 + 북 + 종 / 망치질 |
| 퇴각 / 구조물 파괴 / 성문 돌파 | 비명 + 갑옷 떨어짐 / 붕괴 / 징 + 붕괴 + 함성 |
| 아군 턴 / 적 턴 / 편입 아군 턴 | 전고 셋 + 뿔나팔 / 낮은 북 둘 / 작은 북 |
| 전투 시작 / 승리 / 패배 | 뿔나팔 → 전고 → 함성 / 팡파르 + 환호 + 징 / 구슬픈 선율 + 낮은 징 |
| 일기토 | 칼 부딪힘 + 기합, 필살기 때 환호 |
| 버튼 / 부대 선택 | 목탁 클릭 / 쟁 짧은 음 + 병종 소리(말 울음·발소리·옷깃·노·바퀴) |

## 5. 한계와 다음 단계
- 사람 목소리(함성·비명)는 합성이라 실제 녹음보다 기계적으로 들릴 수 있다.
- 더 높은 품질이 필요하면: (1) CC0 녹음 효과음(예: Kenney Impact Sounds, OpenGameArt 검·충격 팩)을 받아 층에 섞기, (2) 성우·전통 악기 녹음 의뢰. 이 작업 환경에서는 외부 음원 사이트 접속이 막혀 있어 파일을 직접 받아 저장소에 넣어야 한다.

## 6. CC0 녹음 음원 보강 (v2.1)
- 녹음 없이 저작권 문제가 없는 CC0(퍼블릭 도메인) 녹음 190개를 48묶음으로 추가(`public/sfx`, 모노 MP3 1.4MB — 처음엔 WAV 9.3MB).
  - 칼: 칼집에서 뽑기, 베기, 칼날 부딪힘, 모루 금속 울림 / 갑옷·방패·주먹 충격 / 살 베임
  - 활: 화살 바람(휘파람), 나무 꽂힘, 노 걸쇠 / 공성: 나무 갈라짐·삐걱임·래칫, 바위 깨짐·돌 구름, 나무 부서짐
  - 발소리·쇠사슬·옷깃·책장 / 물보라·물결·파도 북 / 불 주문·포성·전격 / 망치질
  - 사람: 기합(그런트), 신음, 비명 / 타악: 큰북, 손북, 목탁, 징 2종, 바라, 종(핸드 차임·벨트리·네팔 손종), 디저리두(뿔나팔 저음)
  - 음악 쟁: VCSL 단짠(베트남 쟁, 오음계 조율) 녹음 16음으로 교체
- 함성은 기합·신음 녹음 6개를 높낮이와 시차를 달리 겹쳐 군중처럼 들리게 만들고 합성 군중을 아래에 깐다.
- 말발굽·환호·책략 시전은 녹음을 겹쳐 만든다(말발굽: 낮춘 목탁+발소리를 세 박 리듬으로, 환호: 높인 기합 여럿 + 합성 군중, 시전: 주문음+옷깃). 말 울음만 가까운 CC0 녹음이 없어 합성음 유지.
- 녹음을 못 불러오면 같은 이름의 합성음으로 자동 대체한다.
- 출처와 원본 파일 목록: `sound-credits.md`.
