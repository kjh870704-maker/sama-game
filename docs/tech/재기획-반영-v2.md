# 사마의전 v2 — 재기획 반영과 아트 개편

2026-09-23. 이번 빌드는 재기획의 첫 제작 단계인 대표 전장 3개를 연결한 개발판이다. 32전장 완성판이 아니다.

## 플레이 가능한 내용

- 연의 지도: 상·중·하 32개 전장의 이름과 제작 상태. 수비전 → 낙양 → 한중 순서로 대표 전장을 해금한다. 중간의 미제작 전장은 건너뛴다고 화면에 명시한다.
- 군의: 사건 설명, 승리·패배 조건, 생존/책략/지휘 특성 중 하나 선택. 각각 본대 HP +25, MP +18, 이동 +1. 구급약 2개는 매 출진 기본 지급된다.
- 사마가 수비전: 비전투 사마의, 창고 확보 기록 유지, 인접 민중 보병 전환, 민중 전멸·필수 장수 퇴각 시 패배, 습격대 격퇴. 창고 확보와 최소 한 부대 무장을 모두 요구한다.
- 낙양: 지참금 3,000전, 첫 매수 1,000전/이후 1,500전, 남문 통행료 1,000전 실제 차감. 무발각·한 번 매수·교전 분기. 매수는 두 번의 적 차례 동안 순찰을 멈춘다. 남문에서 잔액 부족 시 패배한다.
- 한중: 본대·편입 아군·경쟁 우군의 기존 역할을 유지하고 우군의 목표 방향을 표시한다. 속도 인장을 일반 20턴/극한 18턴으로 조정했다. 방향선은 정확한 다음 이동 경로 또는 도착 예정 시간은 아니다.
- 살피기: 행동을 소비해 순찰 경로를 전투 종료까지 공개. 구급약: 행동과 보급 1개를 소비해 최대 HP 40% 회복. 편입 아군과 비전투 인물은 약 사용 불가.
- 해당 전장 일반 완료 시 극한 해금. 난이도별 인장 기록, 결과에서 다음 대표 전장 연결. 장비 제작·군자금 경제 대신 무료 출진 특성을 먼저 연결했다.
- 저장 v2: 명령 재생으로 지참금, 보급, 정찰, 변환, 목표 단계를 복원한다. 직전 명령 무르기와 결과 화면의 목표 전환 직전 복원을 제공한다. 기존 v1 저장은 별도 키로 남기며 자동 변환하지 않는다.

## 미술과 음악

[사용자 지정 전체 레퍼런스](https://namu.wiki/w/삼국지조조전%20Online)의 연의·병과·전투 정보 배치를 참고했다. 원작 파일을 사용하지 않고 신규 제작한 자산을 연결했다.

- 정방 격자 2D 전장. 저해상도 캔버스로 그린 지형을 nearest 보간으로 확대한다. 도트 부대 8종 아틀라스, 이동 보간, 진영 표식, 체력 바, 범위와 목표 표시.
- 먹색 패널, 청동색 명령과 인장, 청록 아군·붉은 적군. 군의/연의 지도/결과 화면의 서체와 여백 통일.
- 청년 사마의 및 소년 사마의·사마랑·사마방 초상. 나머지 장수는 아직 병과 표식을 쓴다. 현재 전장 스프라이트는 병과 공용이며 소년 전용 도트·방향별 동작 시트는 미제작이다.
- 창작 Web Audio 합성 선율을 군영·전투·위기·결과 상태별로 변주한다. 본대 HP 35% 미만 시 위기 리듬을 추가한다. 음악·효과음 개별 볼륨, 탭 비활성 시 정지. 녹음된 전통 악기 음원과 상·중·하 전체 편곡은 후속 작업이다.

## 검증

`npm test`: 94개 통과. `npm run typecheck`, `npm run build`, `npm run validate:stages`로 검사한다.

검증 범위: 세 전장의 일반 승리 경로, 낙양 일반/극한의 무발각·3인장 경로, 한 번 매수 탈출, 교전 분기, 매수·회복·정찰·민중 변환·체크포인트 저장 및 무르기. 브라우저에서 연의 지도→군의→출진, 키보드 이동과 창고 단계 전환, 모바일 메뉴를 확인한다. 이 자동 검증은 사람 대상 밸런스 테스트를 대체하지 않는다.

## 아직 남은 재기획 항목

나머지 29전장, 중·하편 단계별 사건 엔진, 서사 퇴장 구분, 군자금/장비 제작, 동료 대화, 재행동 제한 규칙, 난이도별 개별 적 편성과 목표 차이, 모든 공격의 명중·반사·호위 미리보기, 전용 스프라이트 애니메이션, 전체 음원 제작은 아직 완료하지 않았다. 한중 지도 확장도 기존 지도에서 후속 제작한다.

시나리오 전용 자원/목표 연결은 현재 웹 Session 계층에 있다. 코어만 호출하는 CLI 시뮬레이터는 이 연결을 모두 실행하지 않으므로, 이번 세 전장 완주 검증은 Session 테스트가 기준이다. 다음 단계에서는 일반화된 시나리오 상태 모듈로 이전한다.
