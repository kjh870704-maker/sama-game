# 기믹 모듈 구현 사양 — M-01 ~ M-23

> 상위: [PRD §6 기믹 카탈로그](../prd/PRD-사마의전.md) · [기술설계서 §5](./기술설계서.md)
> 구현: [`events.ts`](../../packages/core/src/events.ts)

## 원칙

**기믹 모듈은 코드가 아니라 "트리거 + 액션의 조합 패턴"이다.**
개별 스테이지를 위한 특수 코드는 `packages/core`에 들어오지 않는다. 새 기믹이 필요하면 먼저 **트리거나 액션 프리미티브를 추가**하고, 스테이지는 그 조합으로만 작성한다.

프리미티브가 늘어나는 것은 정상이지만, **스테이지 ID가 코어 코드에 등장하는 순간 설계 위반**이다.

## 프리미티브 목록

### 트리거

| type | 파라미터 | 의미 |
|---|---|---|
| `battle_start` | — | 전투 시작 |
| `turn_start` / `turn_end` | `turn`, `every`, `side` | 특정 턴 / N턴 주기 |
| `unit_reaches` | `unit`, `region` | 유닛이 영역 도달 |
| `unit_retreats` | `unit` | 유닛 퇴각 |
| `enemy_count_below` | `n` | 적 잔존 수 미만 |
| `region_captured` | `region`, `by` | 영역 점령 |
| `units_adjacent` | `unitA`, `unitB` | 두 유닛 인접 |
| `hp_below` | `unit`, `ratio` | HP 비율 미만 |
| `survive_turns` | `region`, `n` | 생존 시계 경과 |
| `dialogue_choice` | `nodeId`, `optionId` | 선택지 선택 |

### 액션

| type | 파라미터 | 의미 |
|---|---|---|
| `spawn_units` | `units[]`, `side` | 유닛 배치 (적 레벨은 난이도 자동 보정) |
| `apply_effect` / `remove_effect` | `targets`/`side`, `effect`, `duration`, `magnitude` | 상태이상 부여/해제 |
| `change_victory` / `change_defeat` | `conditions[]` | 승리·패배 조건 교체 |
| `convert_unit` | `targets`, `toClass`, `side` | 병종/진영 전환 |
| `grant_control` / `revoke_control` | `targets` | 우군 AI ↔ 편입 아군 전환 |
| `terrain_change` | `region`, `hazard`, `duration` | 지형 위험 지대 설정 |
| `telegraph_aoe` | `region`, `duration` | 피격 예정 타일 예고 (연출 계층) |
| `play_dialogue` / `start_duel` | `dialogueId` | 연출 (연출 계층) |

## 모듈별 구현 사양

### M-01 UNIT_CONVERT — 민중 전환
**사용:** S1-01, S2-04 · **상태:** ✅ 프리미티브 완비

```json
{
  "trigger": { "type": "units_adjacent", "unitA": "sima_yi", "unitB": "civilian_0" },
  "actions": [
    { "type": "convert_unit", "targets": ["civilian_0"], "toClass": "infantry", "side": "ally" }
  ]
}
```

전환된 유닛은 `side: "ally"`(편입 아군)가 되어 **조작 가능 + 도구 불가 + 아군 손실 카운트 포함**. 민중 계수가 매우 낮으므로(§전투규칙 6.1) 전환이 전투력 약 2.5배 상승으로 체감된다.

> **주의:** 전환된 유닛이 아군 손실에 포함되므로, 이 스테이지에 손실 인장을 걸면 **전환할수록 인장이 위험해지는** 역설이 생긴다. 의도한 것이면 UX-11로 반드시 고지한다.

---

### M-02 PATROL_STEALTH — 순찰 회피
**사용:** S1-02 · **상태:** ✅ 구현 및 데이터 검증 완료

```json
{
  "id": "patrol_north", "template": "infantry", "behavior": "patrol", "visionRange": 2,
  "patrolRoute": [{ "x": 6, "y": 4 }, { "x": 10, "y": 4 }, { "x": 10, "y": 8 }]
}
```

순찰 유닛은 경로를 순회하다가 시야(`visionRange`) 안에 적대 유닛이 들어오면 순찰을 멈추고 교전 판단으로 전환한다. 트리거 `unit_spotted`가 발각 시점을 잡아 `play_dialogue`로 넘긴다.

> 진행도(`patrolIndex`)는 유닛 자신의 상태이므로 `decide()`가 갱신한다. AI의 "상태를 바꾸지 않는다" 규칙에서 유일한 예외이며, 스냅샷에 포함되어 무르기에도 안전하다.

---

### M-03 DIALOGUE_GATE — 선택지 분기
**사용:** S1-02, S1-03, S1-11, S2-05, S2-07 · **상태:** ✅ 구현 및 데이터 검증 완료

```json
{
  "trigger": { "type": "dialogue_choice", "nodeId": "warrior_2", "optionId": "wrong" },
  "actions": [{ "type": "apply_effect", "targets": ["sima_yi"], "effect": "bleed", "magnitude": 25 }]
}
```

**오답 페널티는 즉시 패배가 아니라 HP 감소를 기본으로 한다.** 즉사는 리트라이 비용이 너무 커서 스토리 중심 플레이어(P3)를 이탈시킨다. 즉사가 서사상 반드시 필요한 지점(S1-03 무인 조우)에만 예외로 허용하고, **그런 스테이지는 진입 전 세이브 포인트를 보장**한다.

### M-04 BOSS_RUSH — 구간 보스 연전
**사용:** S1-04 · **상태:** ✅ 조합으로 구현 가능

`unit_retreats` → `spawn_units` + `change_victory`의 연쇄. 구간마다 지형/룰이 바뀌므로 `terrain_change`를 함께 건다.

---

### M-05 ESCORT — 호위
**사용:** S1-05, S2-02, S2-08, S2-14, S3-05 · **상태:** ✅ 구현됨

behavior `"escortee"` + `goalRegion`. 보호 대상은 **교전하지 않고** 목적지로만 전진한다 — 공격하게 두면 스스로 적진에 걸어 들어가 호위 자체가 성립하지 않는다. 패배 조건은 `escort_survive`로 평가한다.

---

### M-06 ALLY_AI_SWARM — 대규모 우군 진격
**사용:** S1-06, S1-09 · **상태:** ✅ 구현됨 / ⚠️ 성능 주의

`allyAi` + behavior `"advance"`. **이 모듈은 PRD §9 Tier C에 해당하며, 저사양 실기 검증(PF-06)을 통과해야 머지 가능하다.** 원작 혹평의 근원이 정확히 이 모듈이다.

> PRD Q7(대규모 전투 유지/축소)의 판단 대상. 권고: **유닛 수를 줄이는 대신 우군의 "병목" 연출을 유지**하는 방향. 병목의 답답함은 유닛 수가 아니라 좁은 통로 설계에서 나온다.

---

### M-07 RACE_CAPTURE — 점령 경쟁
**사용:** S1-08 · **상태:** ✅ 구현 및 검증 완료

```json
"victory": [{ "type": "capture", "target": "central_fort", "by": "player" }],
"defeat":  [{ "type": "capture", "target": "central_fort", "by": "allyAi" }]
```

AI는 승리 조건과 **패배 조건을 모두 읽어** 자기 진영의 목표를 판단한다(`objectiveRegion`). 우군에게 `behavior: "race"`를 주면 목표로 직행한다.

**UX 필수:** 우군의 목표까지 남은 거리를 HUD에 상시 표시. 이 UI가 없으면 경쟁 긴장감이 전혀 전달되지 않고, 패배가 갑작스럽게 느껴진다.

---

### M-08 CONSTRUCT — 거점/교량 건설
**사용:** S1-09, S3-04 · **상태:** ✅ 구현됨

```json
{ "trigger": { "type": "region_held", "region": "bridge_site", "by": "player", "n": 2 },
  "actions": [{ "type": "terrain_change", "region": "bridge_site", "terrain": "bridge" }] }
```

점유 시계는 턴이 넘어갈 때 갱신된다. **적과 아군이 영역에 섞여 있으면 어느 쪽도 점유가 아니다**(교전 중) — 이 규칙이 없으면 적 한 명만 밀어 넣어도 건설이 계속되어 버린다.

---

### M-09 ENCIRCLE_LOCK — 포위 구속
**사용:** S1-10 · **상태:** ✅ 구현됨

트리거 `unit_surrounded`는 대상의 인접 4칸이 모두 막혔는지 본다. **유닛뿐 아니라 통행 불가 지형과 맵 경계도 봉쇄로 인정**한다 — 실제 플레이에서 벽에 몰아붙여 가두는 것이 정석 해법이기 때문이다.

```json
{
  "trigger": { "type": "unit_surrounded", "unit": "ma_chao", "by": "ally" },
  "actions": [{ "type": "apply_effect", "targets": ["ma_chao"], "effect": "immobile", "duration": 99 }]
}
```

### M-10 RULE_PICKUP — 효과 획득
**사용:** S1-11(극한) · **상태:** 🔶 프리미티브 추가 필요

적 유닛 선택 시 3턴 지속 효과 획득. 필요: 액션 `offer_effect_choice` + 트리거 `unit_selected`. 극한 S1-11은 이 모듈 하나로 전투 양상이 통째로 바뀌므로 **단독 스파이크가 아니라 별도 모드에 가깝다** — 구현 비용을 M3에 별도 계상할 것.

---

### M-11 TOWER_DEFENSE — 타워 디펜스
**사용:** S2-04 · **상태:** ✅ 조합 가능

적 전원에게 behavior `"escortee"` + 목표 `goalRegion`을 준다 — "목적지로만 가고 싸우지 않는" 성질이 그대로 필요한 동작이다. 플레이어는 민중을 병종 전환(M-01)해 방어선을 구성한다. **적이 반격하지 않으므로 "막기만 하면 되는" 안전한 실험장**이 된다 — 중편 초반 완충 구간으로 적절.

---

### M-12 RESOURCE_DENIAL — 보급 차단
**사용:** S2-06, S3-02 · **상태:** ✅ 조합 가능

`unit_reaches(적 수송대, 자원 영역)` → `apply_effect(적 전체, rally)`. 즉 **막지 못하면 적이 강화된다**. 반대로 수송대를 처치하면 디버프.

---

### M-13 AMBUSH_CHAIN — 다단 복병
**사용:** S2-10, S2-11, S2-12, S2-13, S3-05 · **상태:** ✅ 구현됨

`unit_reaches` → `spawn_units` 연쇄. **UX-08 필수:** 발동한 복병 트리거 좌표는 맵에 영구 표시한다. 표시가 없으면 재도전 시 학습이 불가능하고, 순수 암기 게임이 된다.

---

### M-14 SURVIVE_N_TURNS — N턴 생존
**사용:** S2-13 · **상태:** ✅ 구현됨

`survivalClocks`에 라벨과 시작 턴을 기록하고 `survive_turns` 조건으로 평가. 보통 `change_victory`와 함께 쓰인다(합류 → 7턴 생존).

---

### M-15 OBJECTIVE_FLIP — 목표 반전
**사용:** S2-03, S2-09, S2-14, S3-01, S3-05 · **상태:** ✅ 구현됨

`change_victory` / `change_defeat`. **UX-05 필수:** 전체화면 배너로 고지. 조용히 바뀌면 플레이어는 자기가 왜 졌는지 알 수 없다.

---

### M-16 MASS_CONFUSION — 집단 혼란
**사용:** S2-14 · **상태:** ✅ 구현됨

`apply_effect(side: "player", effect: "confusion")`. 해제 도구(대각성서)를 **인장 보상으로 미리 지급**해 해법을 열어둔다(PRD R-5.6과 같은 패턴).

---

### M-17 RULE_REVERSAL — 전장 룰 역전
**사용:** S3-06 · **상태:** ✅ 조합 가능

```json
{
  "trigger": { "type": "region_captured", "region": "armory", "by": "player" },
  "actions": [
    { "type": "remove_effect", "side": "enemy", "effect": "rally" },
    { "type": "apply_effect",  "side": "player", "effect": "rally", "duration": 99 }
  ]
}
```

**하편의 정서적 정점.** 이 한 번의 점령으로 적 전체 버프가 사라지고 증원이 끊긴다 — "이제 판을 내가 짠다"를 기믹으로 번역한 것. 증원 중단은 주기 스폰 이벤트에 `region_captured` 가드를 추가해 구현한다.

---

### M-18 TELEGRAPHED_AOE — 예고 광역
**사용:** S3-07 · **상태:** 🔶 연출 계층

`telegraph_aoe`로 다음 턴 피격 좌표를 표시 → 다음 턴 `apply_effect`. **회피 가능해야 의미가 있다** — 예고 후 실제 발동까지 최소 1턴을 보장한다.

---

### M-19 HAZARD_FIELD — 지속 피해 지대
**사용:** S2-02, S2-09, S2-10, S3-07 · **상태:** ✅ 구현됨

`terrain_change`로 `fire`/`trap`/`lightning` 설정. 화염 지대 진입 시 화상, 함정은 최대 HP 25% 피해.
**둘 다 유닛을 퇴각시키지 않는다**(HP 하한 1) — §전투규칙 5 참조.

---

### M-20 GUARD_LINK — 호위
**사용:** S2-11, S3-04 · **상태:** ✅ 구현됨

인접한 `guardian` 보유 아군이 피해를 대신 받는다. 대상 자체가 바뀌므로 `formulas.ts`가 아니라 `Battle.damage()` 단계에서 처리한다.

**관통 공격(`penetrate`)은 호위를 무시한다.** 이 예외가 없으면 호위 유닛 하나로 전선이 영구히 잠겨 전투가 성립하지 않는다 — 상대에게 반드시 대응 수단이 있어야 한다. 전환은 1단계만 일어난다(호위가 호위를 부르지 않는다).

---

### M-21 DECOY_SPLIT — 분신 도주
**사용:** S3-02 · **상태:** ✅ 조합 가능

`hp_below` → `spawn_units`(분신 N체, behavior `"flee"`) + 원본 제거. `flee`는 `exit` 영역으로 직행한다. 모든 출구를 막아야 잡을 수 있으므로 **봉쇄 퍼즐**이 된다.

---

### M-22 PROTAGONIST_ABSENT — 주인공 부재
**사용:** S2-03, S3-05 · **상태:** ✅ 데이터만으로 가능

`deployment.forced`에서 사마의를 빼면 끝. **서브 장수 육성을 강제하는 장치**이므로, 해당 스테이지 전에 그 장수들이 출진 가능한 스테이지를 최소 1개 배치해 레벨링 기회를 준다.

---

### M-23 DUEL — 단기접전
**사용:** S2-07 · **상태:** 🔶 연출 계층

`units_adjacent` → `start_duel`. 결과는 사전 정의(승리/무승부)이며 전투 상태에는 연출과 인장만 영향을 준다.
