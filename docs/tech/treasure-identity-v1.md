# 보물 개성 1차 — 2026-10-03

60종 보물에 전용 아이콘 위치와 고유 전투 특성을 연결했다. 기존 능력치 보너스, 등급, 소유/장착 규칙, 외전 해금 조건은 유지한다. 효과는 게임 설계이며 연의의 역사적 효능을 주장하지 않는다.

## 전투 적용
- core/treasure-traits.ts에 60개 ID별 조건과 효과 정의. 도감 설명은 동일 규칙에서 생성한다.
- 관통, 조건부 공격 위력·회심·명중, 반격 억제, 피해 감소·회피, 자기 차례 HP/MP 회복, 험지 이동, 반격 횟수 효과.
- 청강검 물리 방어 25% 관통, 용담창 실제 이동 후 반격 억제, 쌍철극 진영 차례마다 최대 2회 반격, 청낭서 자기 차례 HP 7 회복.
- 등갑: 물리 피해 18% 감소 / 책략 피해 12% 증가. 갑주·보조구의 피해 감소는 곱연산 결합이며 회복은 최대치를 넘지 않는다.
- 이동/대기/공격 소모 여부와 실제 이동 여부를 분리해 조건부 효과를 판정한다. 책략 위력과 물리 위력은 기존 피해 공식에 반영되며 최종 피해 증가율과 동일하지 않다.
- 신규 출진 Deployment.treasureRules=1에만 고유 효과를 부여한다. 이전 전투 저장은 기존 능력치 보너스로 재생하며, 이후 새 출진부터 고유 효과를 사용한다.
