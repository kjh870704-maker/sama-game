# 병종 활용 v1

- 외전 지원 병종 12종 → 17종: 궁병·경기병·중기병·포차·충차 추가. 기존 두 지원 슬롯 유지.
- 들판/숲/강/협로/사당/성곽 지형별 추천 편성 버튼. 선택은 자유이며 실제 출진 부대에 반영. 들판은 궁병+의술사.
- 출진 정비와 전투 장수 정보에 병종 운용 설명·공격 사거리. 배운 회복 책략/실제 사거리로 구성 부족 안내.
- 이동 시 지형 비용과 지형 위력, 공격 대상에 실제 수식의 물리 병종 상성 표시.
- 직접 선택한 충차에도 siegeRam/noCounterAttack 적용. 구조물 피해 3배 및 방어 50% 무시. 기존 성곽 필수 충차 유지.
- 동일 병종 두 부대의 ID 충돌 수정: 병종별 누적 번호를 사용. 기존 고유 병종 편성 ID는 유지.
- 수군은 육상 배치에서 이동 불가하므로 지원 선택에서 제외. 공병의 별도 행동은 후속. 본편 배치와 시나리오 확장은 이번 범위에 포함하지 않음.

## 검증
250개 테스트(지원 17병종 출진/저장 복원, 중복 의술사 편성, 충차 특성, 상성, 추천 유효성), 타입 검사 통과. 브라우저 추천 선택 반영·동일 의술사 2부대 실제 출진/자동 저장 확인.
