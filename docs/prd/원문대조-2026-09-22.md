## 기존 기획·데모에서 구분하거나 고칠 점

| 항목 | 원문에서 확인한 내용 | 기존 자료/데모와 차이 | 재기획 처리 |
|---|---|---|---|
| 상편 흉몽 | 진궁·여포·주유 대결 후 헌제 인접 | 기존 PRD는 4연속 보스 격파로 단순화 | 세 대결 + 이동 구간으로 교정 |
| 낙양 탈출 | 두 번째 뇌물까지 지불하면 성문 통행에 쓸 돈이 부족해짐 | 데모는 반복 뇌물을 실제 자원 대신 선택 기록으로 처리하고 적 전멸 분기로 바꿈 | 지참금·성문 비용·잔액을 실제 전장 자원으로 구현할 계획 |
| 한중 정벌 下 | 승리는 성채 점령, 속도 인장은 일반 20/극한 18턴 | 데모/기존 예시는 수비대장 격퇴를 필수로 추가하고 속도를 12/10턴으로 설정 | 격퇴 선행은 자체 변경으로 명시. 원문 턴수와 신규 맵의 목표값을 구분 |
| 양평관 | 적 8기 이상 퇴각 또는 제갈량 퇴각 | 기존 요약의 추격 저지는 승리 논리를 충분히 표현하지 못함 | OR 조건을 보존하고 신규 압박은 별도 표시 |
| 광릉 | 공략은 연출상 조비 퇴각이 인장 손실에 포함된다고 설명 | 단순 생존 인장 문구와 실제 집계가 다를 수 있음 | 연출상 이탈은 전술 손실과 분리하는 신규 규칙 채택 |
| 목둔 골짜기 | 장합 퇴각은 실패로 제시되지만 후반 각본상 사망 후 승리 전개가 있음 | 공통 ‘퇴각=패배’만으로 옮기면 전장 진행이 모순됨 | 전술 조기 퇴각과 서사 사망 이벤트를 분리 |
| 공손연 | 여러 도주 분신을 출구 통제로 막음 | 단순 보스 체력전으로 축소하면 특징 소실 | 미끼 부대·출구 봉쇄·정찰로 자체 각색 |
| 환성 | 공병 건설과 주변 호위, 관통 공격 주의 | 현 코어의 인접 호위는 4방향이며 원문은 8방향 배치를 설명 | 전장별 호위 범위를 명시하고 테스트할 계획 |
| 고평릉 | 무기고 장악으로 적 강화와 증원을 끊고 부대 구성이 바뀜 | 거점 점령 한 조건만으로는 전투의 전후 차이가 표현되지 않음 | 효과 제거·증원 종료·후계 부대 임무 전환을 하나의 단계 전환으로 명시 |

위 내용은 원문의 주요 차이만 요약한 것이며 전체 공략을 재현한 문서는 아니다. 전장명과 기존 ID 목록은 사용자가 제공한 저장소를 함께 참조했다.

## 그대로 이식하지 않을 요소 — 자체 결정

- 장수 구매·계보 비용과 특정 고레벨/고강화 장비를 전제로 한 해법.
- 선택지를 외워야 하는 즉사, 설명 없는 위치 강제 복귀, 정답을 누락한 면역.
- 실제 조작 유닛의 과도한 증가. 규모감은 장면 연출로 분리.
- 빠른 진행에 불리하게 이전 단계 함정이 뒤늦게 활성화되는 이벤트 구조.
- 일반/극한 수치 공란의 임의 보완 및 원문 공략 의견의 사용자 통계화.

## 재기획에서 새로 제안한 것

2D 도트 아트 방향, 사마의 나이별 초상, 전장별 극한 해금, 기본 보급, 제한적 정찰·지휘 명령, 각본상 손실 분리, 목표 단계별 체크포인트, 상태에 따른 음악 전환은 신규 설계다. 이 요소가 원작에 있었다고 주장하지 않는다.
