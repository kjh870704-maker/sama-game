# 사마의전 — 상·중·하편 재기획 v1

작성: 2026-09-22 · 상태: 다음 개발의 기준이 되는 설계안, 미구현 항목 포함

사용자가 지정한 나무위키 사마의전 및 연결된 상·중·하편을 직접 읽고 재구성했다. 기존 저장소의 32전장 ID를 유지하되, 원문 정보와 자체 설계를 구분한다. 이 문서가 기존 PRD v0.2·스테이지 예시·개발 로드맵과 충돌하면 **새로 제작할 게임의 기획은 이 문서를 우선**한다. 현재 실행 코드의 동작이 이미 바뀌었다는 뜻은 아니다.

관련 문서: [원문 대조와 수정 근거](./원문대조-2026-09-22.md) · [32전장 설계](./캠페인-32전장-v1.md) · [기존 프로토타입 제작 노트](../tech/플레이어블-제작노트.md)

## 1. 만들 게임

**사마의가 살아남는 방법이, 군대를 지휘하는 방법을 거쳐, 권력을 장악하는 방법으로 변해 가는 3부작 턴제 전술 RPG.**

전투마다 플레이어가 답해야 할 질문을 바꾼다.

| 부 | 이야기의 중심 | 플레이어가 하는 일 | 전투가 끝났을 때 남길 감정 |
|---|---|---|---|
| 상편 · 살아남는 자 | 가족, 출사, 조조와 조비 사이에서의 생존 | 이동·설득·호위·소수 부대 운용으로 불리한 조건을 해결 | 살아남았지만 더 깊이 얽혔다 |
| 중편 · 맞서는 자 | 지휘권 확대와 제갈량과의 대결 | 부대를 나누고 보급을 관리하며 함정과 목표 변경에 대응 | 이겼어도 상대의 의도를 다 읽지는 못했다 |
| 하편 · 거머쥐는 자 | 노년, 후계, 군권과 조정 장악 | 거점·연락·증원을 통제해 전투의 조건 자체를 바꿈 | 살아남기 위해 택했던 수가 남을 몰아붙이는 수가 되었다 |

부제는 신규 작업명이다. 상편은 조조의 시대가 끝나는 지점, 중편은 제갈량 사후 오장원, 하편은 왕릉 진압과 사마의의 마지막 회고로 맺는다. 원문에 있는 각색된 사건을 역사적 사실로 단정하지 않는다. 도감에서 ‘역사 배경’과 ‘본작 각색’을 구분한다.

## 2. 기존 데모에서 바꿀 것

| 현재 | 재기획 |
|---|---|
| 두 전장을 메뉴에서 바로 고름 | 이야기 순서대로 열리는 캠페인 지도 + 별도 전투 재도전 |
| 사마의·조진을 권장 레벨로 즉시 지급 | 이야기 합류와 역할 학습, 출진 최소 전력 보장 |
| 기본 이동·공격·풍룡 중심 | 전투마다 호위·차단·설득·정찰·점령 중 다른 해법을 요구 |
| 간략한 등각 벡터 전장과 임시 초상 | 조조전 감각의 2D 도트 전장 + 세밀한 장수 초상 + 제한적인 조명 효과 |
| 공통 배경음과 단순 합성 효과음 | 부별 주제곡, 전장 상태별 편곡, 행동별 효과음 |
| 한중의 소수 수비대와 단순 우군 경쟁 | 진입로별 부대 역할과 우군 진행도를 읽는 완성형 전투 |
| 대화 선택과 승패가 일부 단순화 | 비용·분기·목표 단계·실패 원인을 명시한 시나리오 상태 관리 |

기존 코어, 데이터 로딩, 결정론적 RNG, 클라이언트 저장/무르기는 재사용 후보이다. 현재 그래픽과 합성 음악은 임시 자산으로 남겨 개발 중 실행 가능 상태를 유지한다.

## 3. 한 판의 흐름

**사건 제시 → 군의와 출진 → 전투 → 사건의 결과 → 진영 정비.**

1. 사건 제시: 관계와 갈등 하나만 분명히 보여준다. 대사는 새로 작성하고 다시보기·요약·넘기기를 제공한다.
2. 군의: 지형, 초기 목표, 필수 생존 장수, 알려진 적 특성, 전술 선택의 비용을 확인한다.
3. 출진: 강제 장수와 선택 장수, 편입 아군, 자동 우군을 별도 표시한다. 필요한 공병·회복 역할은 기본 지급한다.
4. 전투: 이동과 행동 각 1회. 목표 단계가 바뀌면 입력을 잠시 멈추고 새 조건을 안내한다.
5. 결과: 승리뿐 아니라 구한 병력, 소비 자원, 선택 결과와 인장을 보여준다. 줄거리상 손실은 전술 손실과 별도 집계한다.
6. 정비: 장비 교체, 특성 선택, 도구 보충, 인물 대화. 도시 건설이나 반복 자원 채집은 넣지 않는다.

일반 전장 8~18분, 주요 전장 15~25분을 **설계 목표**로 둔다. 대화를 포함한 총 플레이 시간은 전장 수만으로 확정하지 않고 실측 후 산정한다.

## 4. 전투 규칙

### 4.1 조작과 진영

- 정사각 격자, 아군 → 편입 아군 → 적군 → 자동 우군 순서를 유지한다. 별도 차례가 비어 있으면 자동으로 넘긴다.
- 편입 아군은 플레이어가 조작하며 별도 임시 장비를 가진다. 도구 사용 제한과 인장 손실 포함 여부를 출진 화면·유닛 정보에 동시에 표시한다.
- 자동 우군은 다음 목적지와 행동 방침을 보여준다. 호위 대상에는 기본적으로 돌격 AI를 부여하지 않는다.
- 대규모 병력의 분위기는 배경 병력·원거리 연출로 표현하고, 실제 조작 유닛은 줄인다. 전투 중 조작 가능한 유닛은 원칙적으로 12기 이하, 예외 16기 이내를 목표로 한다.
- 진영은 색뿐 아니라 테두리 모양과 진영 아이콘으로 구분한다.

### 4.2 정보와 책략

피해 예상, 명중률, 반격 가능 여부, 피해 반사·호위 대상을 공격 확정 전에 표시한다. 반격과 피해 반사가 겹치면 총 위험을 함께 보여준다. 적 면역은 이유와 해제 조건을 갖는다.

풍계는 위치 제어와 안정적인 피해, 화계는 진입 차단, 수계는 수상전, 뇌계는 예고형 범위 압박, 지원계는 회복·해제를 맡는다. 풍룡 하나로 모든 퍼즐을 해결하지 못하도록 목표·적 저항·MP 비용을 조합하되, 해답을 특정 희귀 장비에 묶지 않는다.

회귀 계열의 재행동은 한 유닛당 턴에 한 번, 같은 턴 연쇄 재사용 불가로 설계한다. 원작 공략에서 쓰인 무제한 도구 사용이나 레벨 격차를 필수 해법으로 요구하지 않는다.

### 4.3 정찰과 지휘 — 신규 설계

전체 정치 시뮬레이션 대신 기존 격자 명령에 두 가지 선택을 추가한다.

| 명령 | 비용 | 효과 | 도입 |
|---|---|---|---|
| 살피기 | 해당 유닛 행동 1회 | 지정 구역의 함정 단서 또는 순찰 경로 확인 | 상편 초반 |
| 지휘 | 공용 지휘 횟수 1회, 기본 전투당 2회 | 다음 이동 방향 지정 / 지정 지점 대기 중 시나리오가 허용한 우군 명령 | 상편 호위전부터 |

지휘 횟수는 전장 내 자원으로 시작 시 초기화하며 상점 재화로 구매하지 않는다. 경쟁 우군·각본상 강행군에는 명령이 통하지 않으며 UI에 이유를 표시한다. 일반 난이도는 주요 위험을 기본 표시하고, 극한은 단서와 살피기로 확정 정보를 얻는다. 정답을 외워야만 살 수 있는 숨은 즉사 칸은 사용하지 않는다.

### 4.4 목표 단계와 서사 사건

전장은 명시적인 단계로 진행한다. `잠입 → 협상 → 탈출`, `추격 → 동요 → 철수`처럼 현재 단계마다 승리·실패·이벤트 집합을 따로 둔다.

- 이전 단계 이벤트는 종료 시 비활성화한다. 빠른 처치 때문에 이미 끝난 추격 복병이 철수 단계에 다시 나오지 않게 한다.
- 목표 달성 기록은 단계 전환 후 유지한다. 같은 장소에 계속 서 있어야만 이전 단계가 인정되는 구조를 피한다.
- 각본상 사망/부대 이탈과 플레이어의 전술적 퇴각을 다른 이벤트로 저장한다.
- 목표 전환 직전 자동 체크포인트를 남기고, 무르기는 단계·대화·보급·지형까지 함께 복원한다.
- 대화 중에는 모든 진영의 전투 명령과 AI 진행을 정지한다.

## 5. 인물과 성장

### 5.1 사마의의 세 시기

| 시기 | 역할 | 성장에서 느껴지는 변화 | 시각·음향 |
|---|---|---|---|
| 소년·청년 | 관찰, 이동, 설득 | 공격할 수 없는 상황에서도 남을 움직일 수 있음 | 가벼운 의복, 또렷한 눈매, 적은 악기 |
| 중년 | 책략, 진형 지원, 위험 예측 | 직접 피해보다 부대 전체의 효율이 커짐 | 군막 의관, 절제된 동작, 현악 대선율 |
| 노년 | 지휘, 거점 통제, 후계 지원 | 사전 준비와 명령이 전장의 규칙을 바꿈 | 백발·흰 수염, 느린 동작, 낮은 현과 긴 침묵 |

나이별 초상은 단순 색 교체가 아니라 얼굴·자세·의복을 별도로 제작한다. 노년을 무조건 최강 공격수로 만들지 않는다.

### 5.2 부대 구성

- 상편: 사마랑은 초기 보호·지원, 조비는 정치적 동행, 조진은 전선 돌파, 진군은 회복·보조 역할을 중심으로 설계한다.
- 중편: 장합은 기동, 곽회는 방어·합류, 손례는 전선 유지. 사마사와 사마소는 후계자로서 다른 운용법을 익힌다.
- 하편: 사마사는 규율과 차단, 사마소는 기동과 압박, 등애는 험지·공병 지원, 관구검은 독립 전선을 맡는다.
- 선택 장수는 부마다 2~4명 규모로 먼저 제작하고 확대한다. 원문에 이름이 등장하는 모든 장수를 처음부터 개별 육성 대상으로 만들지 않는다.

위 역할 분담은 **신규 게임 설계**이며 원작 병과·능력치의 정확한 재현을 뜻하지 않는다.

### 5.3 성장 경제

캠페인 장수는 이야기 진행으로 합류한다. 계보 구매·장수 뽑기·반복 레벨 노가다는 넣지 않는다. 기존 엔진의 1~99 레벨 수치는 유지할 수 있으나, 출진 장수의 기본 레벨은 장 진행도에 맞춰 보정한다. 실질적인 선택은 특성 분기와 장비에 둔다.

전투 보상은 군자금, 특성 해금, 장비 제작 재료로 단순화한다. 필수 도구는 출진 때 기본 보급하고, 추가 선택 도구만 군자금으로 교체한다. 패배 시 군자금·캠페인 재고를 소모하지 않는다. 보상이 부족해서 필수 전장을 더 이상 진행할 수 없는 상태는 허용하지 않는다.

특성은 ‘생존 / 책략 / 지휘’ 세 축을 먼저 만든다. 한 번 선택하면 영구 고정하기보다 출진 전 재편성할 수 있게 한다. 정확한 수치와 해금 시점은 S1-01~04 테스트 뒤 확정한다.

## 6. 난이도·인장·실패

일반과 극한 두 난이도만 우선 제작한다. **해당 전장 일반 클리어 시 그 전장의 극한을 해금**한다. 이는 기존 PRD의 부 완주 해금에서 변경한 신규 정책이다. 극한 콘텐츠는 해당 부 출시 때 함께 제공한다.

| 항목 | 일반 | 극한 |
|---|---|---|
| 위험 정보 | 핵심 범위·발동 예고 기본 공개 | 단서 제공, 일부 정찰 필요 |
| 전술 압박 | 초기 실수에서 회복 가능 | 보급·배치·시간 선택을 더 엄격하게 |
| 적 편성 | 역할을 배우기 쉬운 구성 | 기존 역할의 조합과 진입 순서를 변경 |
| 성장 의존 | 기본 지급 장비로 완주 가능 | 희귀 장비 없이도 검증된 해법 제공 |
| 무르기 | 제한 없음, 동일 명령은 동일 확률 결과 | 동일 규칙, 무르기 없는 완주는 별도 기록 |

단순 적 레벨 가산만으로 극한을 만들지 않는다. 동일 기본 데이터에 배치·이벤트·자원 조건의 난이도별 차이를 선언한다. 로더 확장이 필요하다.

인장은 전장당 3개: 승리 / 그 전장의 핵심 임무 / 선택 도전. 속도 인장을 모든 전장에 강제하지 않는다. 세 인장은 숙련된 플레이로 한 판에 모두 획득 가능하게 설계하며, 서로 충돌하도록 강제하던 v0.2 규칙을 폐기한다. 장합의 각본상 사망이나 임무 완료 후 공병 퇴장은 손실 인장에 넣지 않는다.

패배 화면에는 원인, 발생 턴, 직전 목표를 표시한다. 직전 명령 무르기와 전장 재시작을 제공한다. 목표 전환 체크포인트 불러오기는 신규 구현 항목이다.

## 7. 화면과 아트 방향

### 7.1 전장

**2D 도트 기반의 사선 시점 전장**을 채택한다. 현재 데모의 크게 기울어진 등각 보드 시점은 가독성 비교용으로 보관하고, 실제 타일은 직관적으로 이동 범위를 읽을 수 있는 정방 격자로 배치한다. 카메라 회전은 우선 제외한다.

- 초기 아트 테스트 기준: 지형 타일 48×48px, 유닛 48×64px. 정수 배율 확대를 우선하고 UI는 벡터/텍스트로 분리한다.
- 스프라이트: 대기·이동·공격·피격·퇴각. 병종별 실루엣, 무기, 깃발로 작은 화면에서도 구분한다.
- 장수 초상: 일러스트 스타일로 제작해 대화·장수 정보에 사용한다. 전장 도트와 팔레트·의상을 일치시킨다.
- 지형은 통과 가능 여부가 우선이다. 키 큰 건물은 뒤의 유닛을 가릴 때 반투명 처리한다.
- 안개·불씨·비·횃불은 선택 효과이며 저사양 모드에서 끌 수 있다. 조명 때문에 칸 경계가 사라지면 안 된다.

최종 도트 밀도는 S1-01 한 화면과 사마의/보병/공병 3종을 실제 휴대폰에서 비교한 뒤 고정한다. 위 크기는 제작 시험값이다.

### 7.2 부별 미술

| 부 | 팔레트 | 환경 | 컷신 원칙 |
|---|---|---|---|
| 상편 | 흙색·잿빛·작은 청록 포인트 | 불탄 가옥, 좁은 골목, 군영 | 가까운 시선, 도망갈 길이 먼저 보임 |
| 중편 | 청회색·강물·붉은 화염 | 강·산악·군막·불길 | 지휘 지도와 실제 전장의 차이를 강조 |
| 하편 | 먹색·백색·절제된 금색 | 설원, 성벽, 궁성, 빈 조정 | 정적인 구도, 명령 이후 결과를 오래 보여줌 |

### 7.3 UI

PC는 지도 중심, 좌측 부대 목록, 우측 접이식 상세 정보. 모바일은 가로 화면을 우선 설계하고 세로에서도 명령 창을 접어 지도 면적을 확보한다. 터치 대상은 최소 44px, 모바일 본문은 원칙적으로 14px 이상이다.

상단에는 ‘현재 목표 / 필수 생존 인물 / 이번 단계의 남은 턴’을 유지한다. 필요한 전장에서만 순찰 경로, 지참금, 교량 진척, 우군 도착 예상, 보급 잔량, 포격 예고를 추가한다. 버튼에 개발용 ID·기믹 번호는 노출하지 않는다.

## 8. 사운드 방향

하나의 사마의 주제 선율을 세 시기로 변주한다. 전통 현·관악의 음색을 기반으로 하되 전투 정보를 덮지 않도록 낮은 밀도로 편곡한다. 제작 또는 사용 권한이 확보된 음원만 자산 목록에 등록한다.

| 장면 | 음악의 역할 | 효과음 |
|---|---|---|
| 상편 이동·잠입 | 성긴 현과 숨소리 같은 관악, 불안한 여백 | 발소리, 순찰 신호, 문 빗장 |
| 중편 대치·함정 | 두 선율의 교차, 위험 전환 때 리듬 추가 | 경계 북, 화살, 불길, 짧은 목표 변경 신호 |
| 하편 점령·명령 | 낮은 현과 느린 박, 승리 후 과도한 축하 배제 | 군령, 성문, 무기고의 정적 전환 |
| 호로곡 | 생존 단계의 압박을 점진적으로 높임 | 비가 오면 불길이 잦아들고 음악 밀도가 낮아짐 |
| 고평릉 | 무기고 장악 전후의 우세 변화를 음악 층으로 표현 | 적 증원 신호가 끊긴 뒤 아군 명령 신호가 들림 |

초기 자산 범위: 메인 테마 1, 부별 탐색·전투 편곡 6, 위기·결과 공용 큐 4, 효과음 약 20종. 가이드 수량이며 제작 인력·예산 확정 전 일정으로 환산하지 않는다. 전체 음성 더빙은 후순위다.

배경음·효과음·음성 볼륨을 분리한다. 모든 핵심 소리 신호에는 화면 표시를 함께 제공한다. 음악 루프 경계, 무음/복귀, 장면 전환 때 중복 재생을 검증한다. 현재 Web Audio 합성곡은 프로토타입용으로 유지한다.

## 9. 먼저 완성할 대표 전장

32개를 같은 깊이로 한 번에 구현하지 않는다. 재기획의 차별점을 검증하는 순서로 만든다.

| 단계 | 대상 | 완료 기준 |
|---|---|---|
| R0 · 설계 확정 | 이 문서와 32전장 목록 | 원문/신규 설계/미확인 정보를 구분하고 구현과의 차이를 기록 |
| R1 · 첫 경험 | S1-01, S1-02, S1-08 | 비전투 주인공, 잠입 비용, 편입 아군·경쟁이 모두 실제로 작동. 새 아트/음향의 한 전장 완성 |
| R2 · 전환 검증 | S2-13, S2-14, S3-06 | 생존 카운트, 목표 반전, 전장 규칙 변경이 저장·무르기와 함께 동작 |
| R3 · 상편 완성 | 상편 11개 | 일반/극한 완주, 이야기 연결, 출진·성장·보상·인장 통합 |
| R4 · 중편 완성 | 중편 14개 | 함정·서사 퇴장·후계 합류, 여러 조합의 완주 검증 |
| R5 · 하편 완성 | 하편 7개 | 엔딩·회고·재도전과 전편 저장 호환 검증 |

R2는 중·하편의 대표 시스템만 앞서 시험하는 내부 제작 단계다. 출시 순서를 앞당기거나 매주 한 전장을 배포한다는 뜻은 아니다. 플레이어에게는 완성된 부 단위로 제공한다.

성능 목표는 PC 60fps, 선정한 저사양 모바일 30fps다. 기준 기기는 미정이므로 현재 달성 사실로 쓰지 않는다. AI 처리와 연출을 분리하며, 개체 수가 늘어도 입력과 위험 표시가 멈추지 않아야 한다.

## 11. 검증 기준

- 32전장 각각 정상 승리, 주요 실패, 목표 전환 직전 저장/복원, 전환 후 무르기, 인장 경계값을 검증한다.
- 필수 장수가 육성되지 않았거나 희귀 장비가 없어도 기본 보급으로 일반 완주가 가능해야 한다.
- 최소 2개 서로 다른 편성·접근 방식으로 주요 전장 해법을 확인한다. 모든 퍼즐에 억지로 복수 정답을 만들지는 않되 강제 해법은 사전 학습시킨다.
- 빠른 처치·턴 생략·대화 재진입·동시 목표 달성에도 단계가 역행하거나 부대가 중복 생성되지 않아야 한다.
- 자동 AI 시뮬레이션은 회귀 탐지용이다. AI 승률을 사람의 클리어율이나 난이도 완성도의 증거로 사용하지 않는다.
- 첫 사용자 테스트에서 목표 오해, 명령 오류, 무르기 사용 이유, 전장 체류 시간을 기록한다. 목표 클리어율은 이 결과로 수치화한다.

## 12. 현재 결정과 남은 결정

이번 설계에서 채택한 방향은 3부 32전장, 이야기 합류형 장수, 두 난이도, 전장별 극한 해금, 2D 도트 전장과 일러스트 초상, 전장 상태별 음악이다. 사용자 피드백에 따라 조정할 수 있는 **설계 결정**이며 이미 제작됐다는 의미가 아니다.

제작 착수 전 확정할 항목은 목표 기기, 도트 샘플의 최종 밀도, 아트·음원 제작 방식과 예산, 상세 전장 수치다. 원문에서 빈칸인 레벨·인장 조건을 추정값으로 채워 ‘원작 수치’라고 표기하지 않는다.

현재 플레이 가능한 것은 이전 데모 2개 전장이며, 이번 작업에서는 실행 코드를 바꾸지 않았다.
