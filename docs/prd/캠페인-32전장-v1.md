# 사마의전 캠페인 — 32전장 설계 v1

기준: [재기획 v1](./사마의전-재기획-v1.md) · 작성 2026-09-22

**아래 표는 신규 게임의 제안 사양이다.** ID·전장명은 기존 저장소와 대응시키기 위해 유지했다. 목표, 패배 처리, 힌트, 도전 과제는 원문을 그대로 전사한 값이 아니다. 원문 사실과 차이는 [대조표](./원문대조-2026-09-22.md)에 따로 적었다. 미정 턴수·레벨을 완료된 데이터처럼 취급하지 않는다.

## 1. 전장 전체 구성

공통 실패는 해당 전장의 필수 생존 장수가 전술적으로 퇴각하는 경우다. 누가 필수인지 반드시 출진 화면과 전투 HUD에 명시한다. 아래의 실패 조건은 이에 더해지는 주요 조건이다. 각본상 이탈은 별도 처리한다.

### 상편 — 살아남는 자 / 11전장

가족을 지키는 작은 행동부터 참모로서 남의 군대를 움직이는 경험까지 확장한다. 단독 전장과 대규모 전장을 교대로 배치하며 매번 적 전멸을 요구하지 않는다.

| ID · 전장 | 신규 플레이 목표와 주요 실패 | 플레이어가 결정할 것 | 학습·도전·이야기 연결 |
|---|---|---|---|
| S1-01 사마가 수비전 | 창고 확보 → 민중 무장 → 남은 습격대 격퇴. 사마방·형제 퇴각 시 실패 | 위험한 가까운 길과 민중을 먼저 보호하는 우회로 | 공격 불가 주인공으로 이동·인접·보호 학습. 선택 도전은 민중 전원 보호 |
| S1-02 낙양 탈출전 | 두 형제의 남문 탈출. 통행 자금 부족 또는 필수 장수 퇴각 시 실패. 교전 선택은 별도 목표로 전환 | 정찰에 행동을 쓰거나, 한 번의 발각을 돈으로 넘길지 | 보이는 순찰과 한정 자원. 전투 사이 가족 대화로 피난의 대가 제시 |
| S1-03 육혼산 도주전 | 추격자를 따돌리고 출구 도달. 추격 압박이 한계에 도달하면 실패 | 대화에서 얻은 단서로 설득·기만·돌파 선택 | 잘못된 선택은 압박 증가와 경로 변경. 최종 위험 선택 전 결과 경고, 단순 암기 즉사 제거 |
| S1-04 흉몽 | 세 대결을 통과한 뒤 방해 전차 사이로 황제에게 접근 | 상대별로 근접·책략·자원 소모 중 다른 수단 선택 | 개별 구간에 회복/체크포인트. 마지막은 보스 처치가 아닌 이동 문제. 출사에 대한 공포 연출 |
| S1-05 장강 퇴각전 | 최소 한 수송대 탈출. 전멸하면 실패 | 병력을 전방 개척과 후방 방어에 어떻게 나눌지 | 반복 증원의 출현 구역과 간격 표시. 선택 도전은 추가 수송대 구조 |
| S1-06 동관 전투 | 돌파 구역 확보와 주요 적군 격퇴. 보호 대상 조조 퇴각 시 실패 | 진격을 지원하면서 후방 복병에 남길 병력 | 구속 상태로 적 장수의 방어를 해제. 필요한 도구를 기본 보급하고 사용 이유를 사전 시연 |
| S1-07 한중 정벌전 上 | 적 수비망 돌파·섬멸, 주요 인물 보호 | 기병 돌파와 책략 지원의 배치 | 새 강제 기믹 없이 성장 체감. 태자 경쟁의 인물 대화에 분량 배정 |
| S1-08 한중 정벌전 下 | 수비대장 격퇴 → 본대의 중앙 성채 점령. 경쟁 우군 선점 시 실패 | 지원 병력으로 퇴로를 막을지, 본대 진격을 도울지 | 편입 아군 8기의 역할, 반격 없는 원거리 공격. 우군 경로·진행도 상시 표시 |
| S1-09 한중 공방전 上 | 조조 호위 → 교량 건설 → 지정 출구 도착. 건설 수단 전멸 시 실패 | 호위 대상 이동 속도와 다리 확보 타이밍 | 조진의 건설 명령을 명확히 표시. 무한 전멸을 권하지 않는 제한 증원 구조 |
| S1-10 한중 공방전 下 | 강적의 사방을 봉쇄하고 조조를 탈출시킴 | 봉쇄 유지 인원과 탈출로 개척 인원 분배 | 포위 0/4~4/4 표시. 병사도 보호 대상이라는 점을 손실 UI로 연결 |
| S1-11 동오 설득전 | 일반은 논거·상대 성향을 읽어 협상 성사, 극한은 논쟁의 규칙을 전투 퍼즐로 표현 | 확보한 논거를 어느 질문에 사용할지 | 상편에서 본 사건이 논거가 됨. 오답은 신뢰 감소, 소진 시 실패. 질문 직전 체크포인트 |

상편의 정비 장면은 가족·진군·조비·가후와의 관계를 통해 능력을 드러내는 것과 숨기는 것의 긴장을 다룬다. 선택은 대화 반응과 전장 준비에 영향을 주되, 별도의 거대한 가상역사 분기로 확장하지 않는다.

### 중편 — 맞서는 자 / 14전장

전반에는 지휘 범위가 넓어진 성취감을, 후반에는 적이 준비한 전장에 들어간다는 압박을 준다. 사마의가 없는 전투도 캠페인 전체의 부대 육성으로 해결 가능해야 한다.

| ID · 전장 | 신규 플레이 목표와 주요 실패 | 플레이어가 결정할 것 | 학습·도전·이야기 연결 |
|---|---|---|---|
| S2-01 무위 반란 진압전 | 성채를 지키며 반란군 제압. 성채 함락 시 실패 | 두 갈래 구원 경로와 반사 적 처리 담당 | 책략 피해 반사를 미리 보여주어 강한 공격도 위험하다는 점 학습 |
| S2-02 동구 전투 | 수상 교전 → 조비 철수. 탈출 경로 봉쇄 시 돌파 필요 | 전투 인원과 조비 호위대를 언제 분리할지 | 번개는 다음 턴 위험 칸 예고. 수상 이동과 전투 보정을 별도로 설명 |
| S2-03 광릉 전투 | 지정 적 전력 약화 → 조비 탈출 | 사마의 없는 편성에서 회복·돌파·원거리 역할 확보 | 전맵 저격을 대상 예고형 공격으로 재설계. 엔딩 연출의 조비 이탈은 손실 인장에서 제외 |
| S2-04 양양 전투 | 방어 거점에 적이 도달하기 전 모든 공격 파동 저지 | 길목별 병종 선택과 증원 자원 배분 | 고정 궁병·범위 책사·차단 기병이 서로 보완. 책사만 고르면 항상 이기는 해법을 막도록 적 역할 혼합 |

| S2-06 가정 전투 | 수원 보급 차단 → 붕괴한 적의 도주 저지 | 북쪽 보급 차단과 남쪽 출구 봉쇄에 남길 인원 | 물 잔량·보급 이동·허용 도주 수 표시. 선택 도전은 조건을 갖춘 뒤 마속과 대화 |
| S2-07 양평관 추격전 | 지정 규모 적 격퇴 또는 적 지휘관 퇴각 | 구조·추격·단기접전 사이 우선순위 | 시작 작전별 위험 단서를 제시. 잘못된 길목 선택은 큰 불리함으로 이어지되, 설명 없는 아군 삭제는 제거 |
| S2-08 석정 전투 | 사마사·사마소의 목적지 도착 또는 적군 섬멸 | 전방 돌파와 후방의 장애물 제거·지원 사격 | 후방은 이동 후 강제 원위치 대신 고정 지원 모드. 보호 우군의 남은 버팀 시간 표시 |
| S2-09 성고 전투 | 성채 탈환 → 이엄과 대화. 보호 우군 붕괴 시 실패 | 고착 전선을 돕는 일과 실질 목표를 수행하는 일의 차이 | 돌파 불가 구간에는 봉쇄 이유·대체 경로 표시. 공격 낭비로 배우게 만들지 않음 |
| S2-10 상규 전투 | 퇴각로를 차단하며 지정 적 장수 격퇴 | 화염을 우회할지, 정찰 후 함정 구역을 단축할지 | 불길·함정·복병을 차례로 겹침. 적이 탈출로에 도달하면 실패 |

| S2-12 위수 수비전 | 적 도하를 막으며 지정 적 전력 제압 | 강가 고정 방어와 측면 기동 예비대 배분 | 측면 증원 예고 후 대응 시간 제공. 직전 비극 이후 비교적 명료한 전술전 |
| S2-13 호로곡 탈출전 | 분리 부대 합류 → 7턴 생존 → 비로 퇴로 열림 | 먼저 합류할지, 버틸 자리를 만든 뒤 합류할지 | 합류 후의 생존 목표를 시작 전에도 예고. 포격은 표식과 차폐로 대응 |
| S2-14 오장원 추격전 | 추격 대상 저지 → 아군 동요 → 사마의 철수 | 추격 중 남길 회복·해제 자원과 후방 병력 | 전환 즉시 추격 이벤트 종료. 혼란 해제 수단 기본 지급. 후퇴 성공 후 승전 축하 음악을 쓰지 않음 |

전투 사이에는 후계 세대의 등장과 장합·곽회의 시선을 넣는다. 제갈량과의 대결은 지력 수치의 높낮이보다 먼저 준비한 정보와 시간의 차이로 표현한다.

### 하편 — 거머쥐는 자 / 7전장

적에게 당하던 봉쇄·혼란·규칙 변경을 플레이어가 사용하게 한다. 하편 전체를 궁정 정변으로 통일하지 않고 요동·구원·공병전의 군사적 경험을 거쳐 고평릉으로 이어간다.

| ID · 전장 | 신규 플레이 목표와 주요 실패 | 플레이어가 결정할 것 | 학습·도전·이야기 연결 |
|---|---|---|---|
| S3-01 요수 전투 | 양동 부대 전개 → 준비한 신호에 맞춰 적 진형 붕괴·격퇴 | 양동 개시 시점과 진짜 공격 방향 | 중편의 기만을 이제 아군이 사용. 적 혼란은 플레이어의 준비 완료와 연결 |

| S3-06 낙양 점령전 | 두 전선으로 무기고 확보 → 증원/적 강화 중지 → 영녕궁 진입 | 사마의가 버티는 동안 후계 부대가 감수할 위험 | 거점 하나가 전장의 힘을 바꾸는 하편 대표 전장. 통제권 이전·임무 완료 부대 이탈을 명시 |

엔딩의 주요 역사적 귀결은 고정한다. 구조한 인물·민중·병력, 강행군과 기만을 사용한 선택은 엔딩 회고와 인물 대사에 반영한다. 여러 왕조로 갈라지는 대체역사 엔딩은 이번 범위에 넣지 않는다.

## 2. 대표 전장 제작 사양

다음 여섯 전장을 다음 개발의 검증 대상으로 삼는다. 맵 크기·자원·턴 값은 아래에서 ‘원문 기준’이라고 한 경우 외에는 신규 초깃값이다. 실측 전 난이도 완성으로 간주하지 않는다.

### S1-01 — 싸우지 못하는 주인공

- 제안 맵: 16×12, 가문 저택·창고·동문·북문을 구분.
- 조작: 소년 사마의, 사마랑, 사마방, 지원 병력. 사마의의 공격·책략·도구는 금지 이유와 함께 잠금.
- 단계: 창고 확보 → 무장 가능한 민중 표시 → 사마의 인접 시 보병 전환 → 남은 적 격퇴.
- 핵심 선택: 창고로 직행하거나 위협받는 민중을 보호하며 우회. 민중 전환에 필요한 행동과 순서를 미리 설명.
- 의도한 해법: 사마랑과 사마방이 두 진입로를 맡고, 사마의가 창고를 연 뒤 안전한 순서로 민중에게 접근.
- 인장: 승리 / 민중 전원 생존 / 정해진 시간 내 동·북문 모두 안정화. 시간은 테스트 후 설정.
- 검증: 민중 전환 시 ID·HP 비율·이벤트 참조 유지, 중복 전환 불가, 변환 전후 저장/무르기 일치.

### S1-02 — 노잣돈도 이동력이다

- 제안 맵: 현 낙양 데이터를 확장. 적은 위치·순찰 경로·다음 이동 예상·발각 범위를 표시.
- 전장 전용 지참금 도입. 지급액은 문지기 비용과 첫 순찰 뇌물을 동시에 감당하고, 두 번째 뇌물까지는 감당하지 못하도록 계산한다. 캠페인 군자금과 분리.
- 선택 창에 지불 비용·지불 후 잔액·남문 필요액을 표시. 거짓말은 근거가 있는 경우만 유효한 선택이 되며 결과를 되돌릴 수 있다.
- 잠입 승리: 두 형제 모두 남문에 도착하고 통행 비용 지불 가능. 돈을 실제로 소비한 뒤 승리 기록.
- 교전 분기: 전투 목표와 새 위험을 안내하고 확인 후 전환. 원문처럼 매우 불리한 선택이라는 성격은 유지하지만 별도 전멸 시나리오로 정상 완주 검증.
- 의도한 해법: 무발각 우회 또는 한 번만 지불하고 짧은 길. 둘 모두 기본 이동력으로 가능하게 설계.
- 인장: 승리 / 무발각 / 형제의 체력 조건. 세 인장을 동시에 획득할 수 있어야 함.
- 검증: 동일 순찰 접촉으로 한 행동에 여러 번 차감되지 않음, 대화 도중 AI 정지, 비용·분기·원상태 복원.

### S1-08 — 아군과의 경쟁

- 제안 맵: 24×18, 동·서·남 진입로. 본대 2기와 편입 아군 8기의 조작 경험 유지.
- 세 우군 전선은 경로와 교전 시간에 차이를 둔다. 실질 경쟁자는 빠른 서쪽 부대, 다른 전선은 적을 분산시키는 역할. 장수 수는 성능 예산 안에서 제한.
- 단계: 외곽 돌파 → 수비대장 격퇴 → 본대 점령. 수비대장 격퇴를 별도 필수로 두는 것은 **자체 설계**이며 원문 승리 표와 구분한다.
- 무기 역할: 포차는 원거리 제압, 창병은 길목 유지, 책사는 범위·회복 지원, 보병은 호위. 전장 시작 안내에서 한 줄씩 제시.
- 의도한 해법: 지원부대가 적 포격과 후방 기병을 묶고 사마의·조진이 중앙으로 진입. 중앙 선점 뒤 수비대장을 처리하는 역순은 허용하지 않음.
- UI: 우군의 현재 목적지와 도착 예상 범위를 표시. 경로가 막혀 추정이 바뀌면 갱신하고 확정 시간처럼 표시하지 않음.
- 인장: 승리 / 편입 아군 포함 전술 손실 2기 이하 / 신속 점령. 속도 목표는 원문 20/18턴을 초기 비교 기준으로 삼되 새 맵의 실제 플레이로 확정.
- 검증: 적·본대·편입·자동 우군 각각의 점령 자격, 수비대장과 점령의 동시 달성, 우군 선점 후 무르기.

### S2-13 — 합류가 끝이 아닌 전장

- 제안 맵: 22×16, 분리된 두 아군 집단, 협곡 입구, 안전 공간과 우회 통로.
- 출진 전에 ‘합류 후 7턴 버티기’를 공개한다. 합류 순간 7턴 카운터가 시작하며 합류 전 시간은 포함하지 않는다.
- 신규 턴 계약: 합류 직후를 남은 7턴으로 표시하고, 합류 뒤 처음 맞는 적 페이즈부터 적 페이즈가 끝날 때마다 1회 감소. 7번째 적 페이즈 종료 시 필수 인물 생존을 판정한 뒤 비·승리 이벤트 실행. 마지막 적 공격으로 퇴각했다면 패배 우선.
- 의도한 해법: 합류 전에 입구 봉쇄 병력을 배치, 합류 후 회복과 위치 교대를 분산. 모든 적 전멸을 목표로 삼지 않음.
- 포격은 사거리 제약보다 ‘다음 타격 위치·피해·피난 칸’이 중요하다. 회피 불가능한 동시 광역 공격 조합은 금지.
- 인장: 승리 / 손례 보호 / 지정 구조 대상 추가 생존. 턴 압박으로 합류를 무조건 서두르게 만들지 않음.
- 검증: 합류 턴과 카운터 경계, 마지막 생존 판정 순서, 증원 상한, 비 전후 지형과 저장 복원.

### S2-14 — 추격하던 길을 되돌아간다

- 제안 맵: 24×14, 추격로와 철수로가 겹치지만 후퇴 때 가치가 달라지는 안전 지점 배치.
- 추격 단계에는 장완의 목적지 도달이 실패 조건. 그를 저지하면 해당 실패 조건과 추격 증원을 종료한다.
- 전환 단계에서 위치 변화·혼란 대상·해제 수단·새 출구를 한 화면에 보여준다. 상황 변화가 충분히 전달된 뒤 조작을 돌려준다.
- 철수 단계에서는 사마의와 지정 호위 인물의 탈출이 목표. 기본 해제 도구를 지급하고 부대 분산 여부는 플레이어가 선택한다.
- 의도한 해법: 추격에 모든 이동·보급을 소진하지 않고 후위 한 부대를 남겨 탈출로 확보. 빠른 추격도 별도 정상 해법으로 검증.
- 인장: 승리 / 호위 인원 보존 / 구조 임무. 전환 직후의 강제 혼란 자체로 인장이 실패하지 않음.
- 검증: 1턴 장완 격퇴, 함정 미발동 상태의 빠른 전환, 전환 후 장완 재등장 시 이전 ID/목표 오염, 왕복 이동 이벤트 중복.

### S3-06 — 전장의 규칙을 빼앗는다

- 제안 맵: 24×18, 서쪽 사마의 지연전과 동쪽 후계 부대 침투전을 동시에 표시.
- 준비 단계: 적 강화와 증원이 무기고에 연결됨을 알려준다. 무기고를 목표로 보이게 하고 선행 지식이 없더라도 해결 가능하게 한다.
- 무기고 장악 시: 기존 적의 지정 강화 제거, 향후 증원 중지, 아군 돌파 지원 부여. 변한 효과 목록을 즉시 표시.
- 후계 부대는 후방 확보 임무로 전환해 이탈한다. 이탈 이유를 알리고 인장 손실로 집계하지 않음.
- 사마의의 남은 부대가 영녕궁에 진입한다. 화재로 봉쇄될 길은 진입 전 단서 또는 다음 턴 예고를 제공한다.
- 의도한 해법: 서쪽은 생존·차단에 자원을 쓰고, 동쪽은 엄폐와 결사대 호위로 무기고를 조기 확보.
- 인장: 승리 / 후계 형제 생존 / 정해진 증원 회수 이내 무기고 장악. 왕조 교체의 정치적 결과는 후속 대화에서 보여줌.
- 검증: 같은 턴 점령·증원 순서, 점령 직전/직후 복원, 이탈 유닛의 HP와 생존 인장, 잘못된 진영의 무기고 점령 거부.

## 3. 모든 전장에 작성할 제작 카드

실제 JSON을 만들기 전 전장마다 다음 항목을 채운다.

1. 서사 전후 상황과 인물의 변화 1개.
2. 맵 초안, 목표 영역, 시작 배치, 출진·선택·편입·자동 우군 구분.
3. 단계별 진입·완료·실패 조건과 종료해야 하는 이벤트.
4. 전장 고유 자원·도구·정찰 정보·지휘 허용 범위.
5. 일반/극한 차이. 공란은 미정으로 남기고 원작 수치처럼 적지 않음.
6. 의도한 해법과 다른 접근법의 가능 여부.
7. 인장 3개, 손실 집계 대상, 각본상 이탈 예외.
8. 이야기 컷신·초상·도트·배경·음악·효과음의 자산 목록.
9. 정상 완주·실패·이벤트 경계·저장/무르기·성능 검증 항목.
