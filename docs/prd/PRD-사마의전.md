## 1. 제품 개요

### 1.1 한 줄 정의
**사마의전**은 조조전식 턴제 전술 SRPG 위에서, "영웅의 정복기"가 아니라 **"살아남기 위해 괴물이 되어가는 한 인간의 60년"** 을 32개 전투로 그리는 단일 캠페인 제품이다.

### 1.2 왜 사마의인가 — 차별화 포인트

조조전 계열 캠페인은 대부분 "강해져서 이긴다"의 반복이다. 사마의의 생애는 구조적으로 다른 게임 디자인을 요구한다.

| 축 | 일반 SRPG 캠페인 | 사마의전 |
|---|---|---|
| 주인공 포지션 | 처음부터 군주/주력 | 전반부는 **약자·관찰자·수행원** |
| 승리 조건 | 적 전멸 위주 | **생존·도주·호위·설득·지연**이 절반 이상 |
| 성장 서사 | 힘의 확대 | **위장(자기 은폐) → 권력 장악 → 흑화** |
| 감정 | 카타르시스 | 압박감 → 해방감 → 서늘함 |

**핵심 설계 명제:** 3부 전체에 걸쳐 *플레이어가 느끼는 조작의 자유도 자체가 서사*가 되어야 한다.
- **상편**: 내가 컨트롤할 수 없는 것이 너무 많다 (우군이 멋대로 움직이고, 나는 공격조차 못 한다)
- **중편**: 통제 가능한 부대를 얻지만, 적(제갈량)이 판을 짠다
- **하편**: 내가 판을 짠다. 그리고 그 판은 아군을 향한다

### 1.3 타깃 사용자

| 세그먼트 | 비중 목표 | 니즈 | 대응 설계 |
|---|---|---|---|
| **P1. 조조전 향수층 (30~40대)** | 50% | 익숙한 룰, 삼국지 서사 | 원작 조작감 계승, 병종 상성 유지 |
| **P2. 전술 퍼즐러** | 30% | 정답이 있는 고난도 퍼즐 | 극한 난이도 + 인장(도전과제) |
| **P3. 삼국지 서사 팬** | 20% | 캐릭터/스토리 | 일반 난이도 완화, 스킵 가능한 전투 보조 |

### 2.1 목표 (Goals)

| G3 | 2단 난이도(일반/극한)로 P1·P3와 P2 동시 충족 | 일반 클리어율 ≥ 85%, 극한 클리어율 20~35% |

- ❌ 사마의전 외 다른 인물 캠페인 (방통전·제갈량전 등)
- ❌ 원작 조조전과의 세이브 데이터 호환
- ❌ 연재형(주 1회 해금) 출시 — **의도적 배제**, 근거 §10.2

## 5. 난이도 및 도전 체계

### 5.1 2단 난이도

| | 일반 (Normal) | 극한 (Extreme) |
|---|---|---|
| 해금 | 처음부터 | **해당 부 일반 완주 후 즉시** |
| 적 레벨 | 스테이지별 27~62 등 저레벨 | 일반 +30~40 (67~94) |
| 적 특성 | 일부 부여 | 전 장수 다중 특성 + 보물 |
| 목표 | 스토리 완주 | 퍼즐 해법 탐색 |
| 대상 | P1, P3 | P2 |

> **R-5.1 (필수):** 극한 난이도는 **해당 부 일반 완주 즉시 해금**한다. 원작처럼 "전편 완결까지 미해금" 방식은 금지 (§10.2 참조).

> **R-5.2:** 일반 난이도에서도 적 장수는 **특성을 일부 보유**한다 (장비는 미착용). "일반은 무지성 클리어"가 되지 않게 하되, 레벨 격차로 완충한다.

### 5.2 인장 (도전 과제)

각 스테이지는 **인장 3개**를 가진다.

| 슬롯 | 성격 | 예시 |
|---|---|---|
| 인장 1 | **클리어** (항상 획득) | 전투 승리 |
| 인장 2 | **속도** | N턴 이내 승리 (극한은 -1~-2턴) |
| 인장 3 | **조건부** | 아군 전원 생존 / 특정 적 퇴각 / 특정 우군 생존 / 주머니 미착용 / 특정 이벤트 발생 |

인장 설계 규칙:
- **R-5.3:** 인장 2와 3은 **동시 달성이 상충하도록** 설계한다(속도 vs 안전). 2회차 플레이 동기.
- **R-5.4:** "주머니 미착용" 인장은 **1인 플레이 스테이지에만** 부여한다. 다인 전투에 걸면 저레벨 유저가 영구 차단된다.
- **R-5.5:** **편입 아군/우군이 아군 생존 카운트에 포함되는 경우, 인장 텍스트에 명시**한다. (원작 2-3 "아군 2부대 미만 퇴각"이 실제로는 전원 생존이었던 사례 → 사양 위반으로 간주)

### 5.3 보상 루프

| 단위 | 보상 |
|---|---|
| 스테이지 클리어 | 경험치, 금전, 소모 도구 |
| 인장 개별 | 소모 도구 / 재화 |
| 인장 100% (부 단위) | 일반: 보물 조각 / 극한: 상위 보물 교환권 |
| 업적 100% (부 단위) | 일반: 금전·은전 / 극한: **5★ 고유 장비** |

> **R-5.6:** 상편 일반 인장 보상에 **MP 공격 소모품**을 배치한다 (극한 1-11 설전 전투의 사실상 필수 해법). 난이도 게이트를 보상 루프로 미리 열어주는 설계.

## 9. 성능 요구사항 — **원작 최대 실패 지점 대응**

원작 사마의전 상편은 "조조전 온라인 역사상 최대 규모 전투"를 구현했으나, **저사양 기기 렉으로 혹평**을 받았고 중편에서는 해당 기믹 자체를 삭제해야 했다. 이는 기믹의 문제가 아니라 **성능 예산 부재**의 문제다.

### 9.1 성능 예산

| 등급 | 최대 동시 유닛 | 목표 FPS (기준 기기) | 적용 스테이지 |
|---|---|---|---|
| **Tier A** | ≤ 20 | 60 | 1인 전투, 소규모 |
| **Tier B** | ≤ 40 | 60 | 대부분의 전투 |
| **Tier C** | ≤ 80 | **30 하한 보장** | 대규모 (1-6, 1-10, 3-6) |
| **금지** | > 80 | — | 설계 반려 |

### 9.2 필수 최적화 요구사항

| ID | 요구사항 | 우선순위 |
|---|---|---|
| PF-01 | **적 턴 일괄 처리 모드** — 적 AI 이동을 개별 연출 없이 배치 실행 | P0 |
| PF-02 | 화면 밖 유닛 애니메이션 **컬링** | P0 |
| PF-03 | 유닛 스프라이트 **아틀라스 배칭** (드로우콜 상한 명시) | P0 |
| PF-04 | **저사양 모드 자동 감지** — 이펙트 간소화 + 자동 쾌속 | P0 |
| PF-05 | AI 탐색 연산 **프레임 분산(time-slicing)**, 1프레임 예산 초과 금지 | P0 |
| PF-06 | Tier C 스테이지는 **기준 저사양 기기 실기 검증 통과 후** 릴리즈 | P0 |

### 9.3 기준 기기
저사양 기준 기기를 1종 지정하고, **Tier C 스테이지는 이 기기에서 30FPS/전투 완주 검증을 통과해야 머지 가능**하다. (기기 선정은 §13 미결)

## 10. 릴리즈 전략

### 10.1 출시 단위

| 단계 | 내용 | 산출물 |
|---|---|---|
| **M1** | 엔진 기반 + 기믹 모듈 M-01~M-10 | 플레이 가능 프로토 3스테이지 |
| **M2** | **상편 11스테이지** 일반+극한 동시 | 상편 정식 출시 |
| **M3** | **중편 14스테이지** 일반+극한 동시 | 중편 출시 |
| **M4** | **하편 7스테이지** + 캠페인 완결 | 정식 완결 |

### 10.2 연재형 출시 금지 — 근거

원작은 중편을 **주 1회 1편 해금**하는 연재형으로 운영했고, 아래 이유로 실패로 평가되었다. 본 제품은 이를 반복하지 않는다.

| 실패 요인 | 본 제품 대응 |
|---|---|
| 완결 전까지 극한 난이도 미해금 → 코어 유저 이탈 | **부 완주 즉시 극한 해금** (R-5.1) |
| 일괄 출시 대비 화제성 분산 | **부 단위 일괄 출시** |
| 연재 콘텐츠가 1종뿐이라 주간 리텐션 형성 실패 | 연재 미채택 |

> **R-10.1:** 부 단위 출시 시 **일반과 극한을 동시 제공**한다. 난이도 분리 출시 금지.
