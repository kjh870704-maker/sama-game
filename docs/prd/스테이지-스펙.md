# 스테이지 상세 스펙 — 작성 템플릿 및 예시

> **이전 버전 예시:** 아래 S1-08의 12/10턴, 인장 상충 의무 등은 v0.2 사양입니다. 신규 제작은 [32전장 설계 v1](./캠페인-32전장-v1.md)의 대표 전장 사양과 제작 카드를 사용합니다. 수비대장 격퇴 선행은 원문 규칙이 아닌 자체 설계입니다.

> 상위 문서: [`PRD-사마의전.md`](./PRD-사마의전.md)
> 32개 스테이지는 모두 아래 템플릿으로 1장씩 작성한다. 데이터 스키마는 [`../data/stage-schema.json`](../data/stage-schema.json).

---

## 작성 규칙

1. **기믹은 §6 모듈 카탈로그의 ID로만 기술한다.** 카탈로그에 없는 기믹이 필요하면 먼저 모듈을 추가 등록한다 (R-7 코드 파편화 방지).
2. **인장 2(속도)와 인장 3(조건)은 상충하도록** 설계한다 (R-5.3).
3. 편입 아군이 있으면 **아군 생존 카운트 포함 여부를 인장 note에 반드시 적는다** (R-5.5).
4. 성능 Tier와 최대 동시 유닛 수를 반드시 기재한다 (§9).
5. **"의도한 해법(Intended Solution)"을 1개 이상 반드시 기술한다.** 해법이 안 적히는 스테이지는 설계가 안 끝난 것이다.

## 예시 작성본 — S1-08

## S1-08 은밀한 시선 — 한중 정벌전 下

### 1. 서사 목적
사마의가 "참모로서의 유용성"을 증명해야 하는 첫 전투. 아군 전력은 최소인데 **우군이 경쟁자로 등장**하여, 플레이어에게 처음으로 *"아군보다 빨라야 한다"* 는 압박을 준다.
플레이어가 느껴야 할 감정: **조바심**.

### 2. 전투 정의
| 항목 | 내용 |
|---|---|
| 맵 | 중앙 성채 + 동/서/남 3개 진입로 |
| 강제 출진 | 사마의, 조진 |
| 선택 출진 | 없음 |
| 출진 슬롯 | 2 |
| 편입 아군 | 포차 ×2, 창병 ×2, 책사 ×2, 보병 ×2 — **조작 O / 도구 X / 생존 카운트 O** |
| AI 우군 | 서문 부대(강함·직선 루트), 남문 부대(강하나 발이 묶임), 동문 부대(약함·우회) |

### 3. 승리·패배 조건
- **승리:** 성채 수비대장 퇴각 → 아군이 중앙 성채 점령 (순차)
- **패배:** 사마의 퇴각 / 조진 퇴각 / **우군이 먼저 성채 점령**

> 점령만을 승리 조건으로 두면 **수비대장을 무시하고 빈 성채 칸을 밟는 것**이 최적해가 되어, §8의 의도한 해법이 성립하지 않는다. 헤드리스 시뮬레이션이 실제로 이 경로를 찾아냈다.

### 4. 인장
| 슬롯 | 일반 | 극한 | 비고 |
|---|---|---|---|
| 1 | 전투 승리 | 전투 승리 | |
| 2 | 12턴 이내 승리 | 10턴 이내 승리 | 속도 |
| 3 | 아군 3부대 미만 퇴각 | 아군 3부대 미만 퇴각 | **편입 아군 8기 포함** ⚠️ |

> 인장 2·3 상충: 빠르게 밀면 편입 아군이 녹고, 안전하게 가면 서문 우군에게 성채를 뺏긴다.

### 5. 기믹
| 모듈 | 적용 방식 |
|---|---|
| M-07 RACE_CAPTURE | 서문 우군이 실질 경쟁자. 아군보다 빠르게 중앙 도달하면 즉시 패배 |
| M-08 CONSTRUCT | (미적용 — 본 스테이지는 점령만) |

### 6. 이벤트 타임라인
| 트리거 | 액션 |
|---|---|
| `battle_start` | 편입 아군 8기 배치, 우군 3부대 각 진입로 진격 개시 |
| `unit_reaches(player, central_region)` | 중앙 수비 장수들이 플레이어 쪽으로 어그로 집중 |
| `region_captured(central_fort, ally_ai)` | 패배 처리 |

### 7. 적 구성
| 장수/유닛 | 일반 Lv | 극한 Lv | 주요 특성 |
|---|---|---|---|
| 보스(성채 수비대장) | 23 | 63 | 무제한 반격, 재반격, 반격 강화, 무반격 공격 |
| 부장 A | 23 | 63 | 물리 공격 강화, 주위 방해, 연속 책략 면역 |
| 부장 B | 23 | 63 | 주위 견고, 전화위복, 역전용사 |
| 부장 C | 23 | 63 | 상태이상 면역, 연속 책략(강화) |
| 부장 D | 23 | 63 | 무작위 하강 공격 |

### 8. 의도한 해법 (Intended Solution)
1. **1턴:** 사마의의 광역 책략으로 성문 + 우측 보병 제거 → 포차 2기의 **무반격 공격**으로 적 포차 선제 타격 → 책사의 **연속 책략**으로 마무리.
2. **2턴:** 좌측 관문 보병 제거 후 그 자리에 **창병 배치**. 지형 상성 + 물리피해감소로 북서 경기병 라인을 길막.
3. 창병 HP 소진 시 2번째 창병과 교대, 손상된 창병은 우측 관문(회복 지형)으로 이동.
4. 포차·창병이 좌측 증원을 처리하는 동안 **사마의·조진은 직행**. 조진은 지형 상성이 낮으므로 딜은 사마의가 담당.
5. 보스는 **반격 특성 스택**을 보유 → 원킬 가능한 HP까지만 깎고 다음 턴 시작과 동시에 처치, 조진을 성채에 진입.

### 9. 난이도·성능
| 항목 | 값 |
|---|---|
| 권장 레벨 (일반 / 극한) | 40 / 80 |
| 목표 클리어율 (일반 / 극한) | 85% / 30% |
| 예상 소요 턴 | 10~14 |
| 최대 동시 유닛 | 38 |
| 성능 Tier | B |

### 10. UX 고지 사항
- 전투 시작 시 **"우군이 먼저 성채를 점령하면 패배"** 배너 표시
- 우군 3부대의 **현재 성채까지 남은 거리**를 HUD에 상시 표시 (경쟁 긴장감의 핵심 UI)
- 편입 아군 8기가 **아군 생존 인장에 포함됨**을 고지 (UX-11)
