## 현재 상태 (2026-10-08 갱신)

- 연의(정사) 32전장이 모두 실행 가능하다. 연의 모든 전투 장에 사마의의 선택지가 하나 이상 있고, 고른 길은 표식으로 남아 뒤 장면 대사와 결말 회고에 쓰인다.
- 32전장 설계 문서와 달리, 실제 게임은 **운명의 갈림길 11곳**에서 가상 역사로 갈라진다. 가상 루트 22개 + 신세력 루트 5개, 루트마다 가상 전장 3장 + 우두머리 1장, 선택으로 바뀌는 대체 전장 22장, 결말 17종(일반 15 + 신세력 2).
- 전투 화면과 출진 전 정비 모두 스테이지의 실제 판정에서 만든 승리·패배 조건을 보여 준다. 피난민·호송 대상·지켜야 할 장수는 한 번의 공격으로 최대 체력의 40%를 넘게 잃지 않는다(「버팀」).
- 극한 난이도의 출진 제한은 인원수가 아니라 병종 단계별 코스트 합계다.
- 이야기 중 일기토·설전도 전투 중 겨루기와 같은 효과음을 낸다.
- 구현 상세와 변경 이력은 [`../tech/지속개발-현황.md`](../tech/지속개발-현황.md)를 본다.
